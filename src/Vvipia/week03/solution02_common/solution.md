# 문제 이름: 모의고사

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 배열, 완전탐색, 나머지 연산, ArrayList, Stream  
**소요 시간:** 미기록  
**AI 질문:** O (반복 패턴 처리, 나머지 연산, 최댓값 계산 및 공동 1등 처리)

## 1. 문제 요약

수포자 3명이 정해진 패턴에 따라 문제의 답을 찍을 때, 정답 배열 `answers`와 비교하여 가장 많은 문제를 맞힌 사람의 번호를 배열로 반환한다.

- 입력: `answers = [1, 2, 3, 4, 5]`
- 출력: `[1]`
- 추가 예시: `[1, 3, 2, 4, 2]` → `[1, 2, 3]`

각 수포자의 반복 패턴은 다음과 같다.

- 1번: `[1, 2, 3, 4, 5]`
- 2번: `[2, 1, 2, 3, 2, 4, 2, 5]`
- 3번: `[3, 3, 1, 1, 2, 2, 4, 4, 5, 5]`

## 2. 나의 문제 접근 법

1. 수포자 3명의 반복되는 정답 패턴을 각각 배열로 선언한다.
2. 각 수포자의 정답 개수를 저장할 `scores` 배열을 생성한다.
3. `for`문을 사용하여 `answers` 배열을 순회한다.
4. `i % 패턴.length`를 이용하여 각 수포자의 반복 패턴에 해당하는 값을 가져온다.
5. 실제 정답과 수포자의 답이 일치하면 해당 수포자의 점수를 증가시킨다.
6. `Math.max()`를 사용하여 세 수포자의 점수 중 최댓값을 구한다.
7. `ArrayList`에 최고 점수를 받은 수포자의 번호를 모두 추가한다.
8. `stream().mapToInt(Integer::intValue).toArray()`를 이용하여 `List<Integer>`를 `int[]`로 변환해 반환한다.

## 3. 시간 복잡도

- `answers`의 길이를 N이라고 가정한다.
- 각 수포자의 패턴을 배열로 선언하는 데 O(1)이 소요된다.
- `answers`를 순회하면서 세 수포자의 답을 비교하는 데 O(N)이 소요된다.
- `Math.max()`를 이용한 최고 점수 계산은 O(1)이다.
- 최고 점수를 받은 수포자를 찾는 과정은 최대 3명을 확인하므로 O(1)이다.
- 결과 배열로 변환하는 과정도 최대 3개 원소만 처리하므로 O(1)이다.
- 따라서 전체 시간 복잡도는 **O(N)**이다.

## 4. 시행착오 및 배운 점

- 처음에는 수포자의 반복 패턴을 배열로 선언하고 `answers`를 순회하는 구조까지 작성했다.
- 문제 수가 패턴 길이보다 많을 때 배열 인덱스를 어떻게 처리해야 하는지 고민했다.
- 나머지 연산자 `%`를 사용하면 정해진 패턴을 반복해서 접근할 수 있다는 것을 배웠다.
- `i % 패턴.length`를 사용하면 인덱스가 패턴 길이를 초과하지 않고 처음부터 반복된다는 점을 이해했다.
- 각 수포자의 점수를 개별 변수 대신 `scores` 배열로 관리할 수 있다는 것을 배웠다.
- `Math.max()`를 중첩하여 세 수포자의 점수 중 최댓값을 구하는 방법을 알게 되었다.
- 최고 점수를 받은 사람이 여러 명일 수 있으므로 최댓값과 일치하는 모든 수포자를 결과에 추가해야 한다는 점을 배웠다.
- `ArrayList`를 사용하면 결과에 포함될 수포자의 수가 정해지지 않아도 유연하게 저장할 수 있다는 것을 알게 되었다.
- 수포자의 번호를 1번부터 순서대로 확인하면 별도의 정렬 없이 오름차순 결과를 만들 수 있다는 것을 배웠다.
- `mapToInt(Integer::intValue)`를 사용하여 `List<Integer>`를 `int[]`로 변환하는 방법을 배웠다.
