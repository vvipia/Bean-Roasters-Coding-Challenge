# K번째수

## 1. 문제 정보
- 플랫폼: 프로그래머스
- 난이도: Level 1
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42748
- 사용 언어: Java

## 2. 문제 설명
배열에서 지정된 범위의 숫자를 잘라 오름차순으로 정렬한 뒤, K번째에 위치한 숫자를 구하는 문제입니다.

## 3. 접근 방법
문제에서 요구하는 과정을 배열 자르기, 정렬하기, K번째 숫자 찾기의 세 단계로 나누어 생각했습니다.

1. `commands` 배열을 반복문으로 순회합니다.
2. `Arrays.copyOfRange()`를 사용해 지정된 범위의 배열을 복사합니다.
3. `Arrays.sort()`를 사용해 오름차순으로 정렬합니다.
4. 정렬된 배열에서 K번째 숫자를 찾아 결과 배열에 저장합니다.
5. 모든 명령을 처리한 뒤 결과 배열을 반환합니다.

## 4. 핵심 개념
- `Arrays.copyOfRange()`: 배열의 특정 범위를 복사하는 메서드
- `Arrays.sort()`: 배열을 오름차순으로 정렬하는 메서드
- `int[][]`: 2차원 정수 배열
- 배열 인덱스: Java 배열은 0부터 시작합니다.

## 5. 어려웠던 점
배열의 인덱스가 0부터 시작하기 때문에 문제에서 말하는 번째와 실제 배열 인덱스가 다르다는 점이 헷갈렸습니다.

또한 `Arrays.copyOfRange()`는 시작 인덱스를 포함하지만 끝 인덱스는 포함하지 않는다는 점을 새롭게 알게 되었습니다.

## 6. 새로 배운 점
- `Arrays.copyOfRange()`로 배열의 일부를 복사할 수 있다는 것을 배웠습니다.
- `Arrays.sort()`를 이용하면 배열을 오름차순으로 정렬할 수 있다는 것을 알게 되었습니다.
- 오름차순과 내림차순의 차이를 복습했습니다.
- `int[]`와 `Integer[]`의 차이, `Collections.reverseOrder()`의 사용 조건을 배웠습니다.

## 7. 시간 복잡도
- 시간 복잡도: O(M × N log N)
    - N: 원본 배열의 길이
    - M: 명령의 개수
- 공간 복잡도: O(N + M)
