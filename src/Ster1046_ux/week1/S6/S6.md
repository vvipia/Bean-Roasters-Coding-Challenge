# 문제 이름: 폰켓몬

- **출처:** 프로그래머스
- **난이도:** Lv.1
- **유형:** HashSet, 배열
- **소요 시간:** 미기록
- **AI 질문:** O

## 1. 문제 요약

폰켓몬의 종류 번호가 담긴 배열 `nums`가 주어진다.
전체 마릿수의 절반을 선택할 때, 가져갈 수 있는 서로 다른 종류 수의 최댓값을 반환한다.

- 입력: `[3, 1, 2, 3]`
- 출력: `2`

## 2. 나의 문제 접근 법

1. 중복된 번호를 제외하기 위해 `HashSet<Integer>`를 생성한다.
2. 반복문으로 배열의 모든 번호를 HashSet에 넣는다.
3. `kinds.size()`로 서로 다른 종류 수를 구한다.
4. `nums.length / 2`로 선택할 수 있는 마릿수를 구한다.
5. 종류 수와 선택할 수 있는 마릿수 중 작은 값을 반환한다.

## 3. 시간 복잡도

- **평균 O(N)** — N은 배열의 길이이며, 모든 번호를 HashSet에 한 번씩 넣는다.
- **공간 복잡도: O(K)** — K는 서로 다른 종류 수이며, HashSet에 K개의 번호를 저장한다.

## 4. 시행착오 및 배운 점

- HashSet을 처음 사용하면서 중복된 값을 제외하고 종류 수를 구하는 방법을 배웠다.
