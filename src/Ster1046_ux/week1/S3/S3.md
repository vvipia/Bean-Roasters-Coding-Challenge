# 문제 이름: 삼각형의 완성조건 (1)

- **출처:** 프로그래머스
- **난이도:** Lv.0
- **유형:** 조건문, 구현
- **소요 시간:** 32분 3초
- **AI 질문:** O

## 1. 문제 요약

세 변의 길이가 담긴 배열 `sides`가 주어진다.
삼각형을 만들 수 있으면 1, 만들 수 없으면 2를 반환한다.

삼각형이 되려면 가장 긴 변이 나머지 두 변의 합보다 작아야 한다.

- 입력: `[199, 72, 222]`
- 출력: `1`
- 이유: `222 < 199 + 72`를 만족한다.

## 2. 나의 문제 접근 법

1. 첫 번째 변과 두 번째 변을 비교하여 큰 값을 `longSide`에 저장한다.
2. 세 번째 변이 `longSide`보다 크면 값을 갱신한다.
3. 세 변의 합에서 `longSide`를 빼서 나머지 두 변의 합을 구한다.
4. 나머지 두 변의 합이 가장 긴 변보다 크면 1을 반환한다.
5. 그렇지 않으면 2를 반환한다.

## 3. 시간 복잡도

- **O(1)** — 입력은 항상 세 변이며, 일정한 횟수의 비교와 계산을 수행한다.
- **공간 복잡도: O(1)** — 일정한 수의 변수만 사용한다.

## 4. 시행착오 및 배운 점

- 세 변의 합에서 가장 긴 변을 빼면 나머지 두 변의 합을 구할 수 있다.
