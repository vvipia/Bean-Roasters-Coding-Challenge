# 문제 이름: 숨어있는 숫자의 덧셈 (1)

- **출처:** 프로그래머스
- **난이도:** Lv.0
- **유형:** 문자열, 구현
- **소요 시간:** 11분 57초

## 1. 문제 요약

문자열 `my_string`에서 숫자만 찾아 합계를 반환한다.
연속된 숫자도 각각 한 자리 숫자로 취급한다.

- 입력: `"aAb1B2cC34oOp"`
- 출력: `10`
- 계산: `1 + 2 + 3 + 4 = 10`

## 2. 나의 문제 접근 법

1. 합계를 저장할 변수 `answer`를 0으로 초기화한다.
2. 반복문과 `charAt(i)`로 문자열에서 한 글자씩 꺼낸다.
3. 꺼낸 문자가 `'0'` 이상이고 `'9'` 이하인지 확인한다.
4. 숫자라면 `ch - '0'`으로 정수로 변환하여 합계에 더한다.
5. 모든 글자를 확인한 뒤 합계를 반환한다.

## 3. 시간 복잡도

- **O(N)** — 문자열의 길이 N만큼 각 글자를 한 번씩 확인한다.
- **공간 복잡도: O(1)** — 일정한 수의 변수만 사용한다.

## 4. 시행착오 및 배운 점

- 숫자 문자에서 `'0'`을 빼면 해당 숫자의 정수 값으로 변환할 수 있다는 점을 배웠다.
