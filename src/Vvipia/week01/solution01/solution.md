# 문제 이름: 자연수 뒤집어 배열로 만들기

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 구현, 수학  
**소요 시간:** 11분  
**AI 질문:** X

## 1. 문제 요약

자연수 `n`이 주어졌을 때, 각 자릿수를 역순으로 배열에 저장하여 반환한다.

- 입력: `12345`
- 출력: `[5, 4, 3, 2, 1]`

## 2. 나의 문제 접근 법

1. 배열의 크기를 결정하기 위해 `while`문으로 자연수의 자릿수를 계산한다.
2. 계산한 자릿수만큼 배열을 생성한다.
3. `% 10`으로 마지막 자릿수를 추출하여 배열에 저장한다.
4. `/ 10`으로 마지막 자릿수를 제거하고 반복한다.

## 3. 시간 복잡도
- 입력되는 n의 값이 커져도 10을 나누며 nScale에 저장하므로 O(log N)

## 4. 시행착오 및 배운 점
- % 10 을 하면 가장 뒷 자리만 남아 순서대로 배열에 넣으면 되는데, 맨 처음에 아무 생각없이 반복문의 방향을 반대로 만들어 원하는 결과가 나오지 않았다.
