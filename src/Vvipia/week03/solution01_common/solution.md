# 문제 이름: 가장 큰 수

**출처:** 프로그래머스  
**난이도:** Lv.2  
**유형:** 배열, 정렬, Comparator, 문자열  
**소요 시간:** 미기록  
**AI 질문:** O (Comparator, compareTo, 문자열 변환 및 결합)

## 1. 문제 요약

0 또는 양의 정수가 담긴 배열 `numbers`가 주어졌을 때, 숫자들의 순서를 재배치하여 만들 수 있는 가장 큰 수를 문자열로 반환한다.

- 입력: `numbers = [6, 10, 2]`
- 출력: `"6210"`
- 추가 예시: `[3, 30, 34, 5, 9]` → `"9534330"`

## 2. 나의 문제 접근 법

1. 숫자를 이어 붙여 비교해야 하므로 `int[]`를 `String[]`로 변환한다.
2. `Arrays.sort()`와 `Comparator`를 사용하여 정렬 기준을 직접 정의한다.
3. 두 문자열 `a`, `b`를 이어 붙인 `(a + b)`와 `(b + a)`를 비교한다.
4. `(b + a).compareTo(a + b)`를 사용하여 더 큰 수를 만들 수 있는 순서로 정렬한다.
5. `String.join("", strArr)`을 사용하여 정렬된 문자열을 하나로 합친다.
6. 모든 원소가 0인 경우 `"000"`이 아닌 `"0"`을 반환하도록 예외 처리한다.

## 3. 시간 복잡도

- `numbers`의 길이를 N이라고 가정한다.
- `int[]`를 `String[]`로 변환하는 데 O(N)이 소요된다.
- `Arrays.sort()`를 이용한 정렬에 O(N log N)이 소요된다.
- `String.join()`을 이용한 문자열 결합에 O(N)이 소요된다.
- 숫자는 최대 1,000이므로 문자열 비교와 결합 비용은 상수로 취급할 수 있다.
- 따라서 전체 시간 복잡도는 **O(N log N)**이다.

## 4. 시행착오 및 배운 점

- 처음에는 `Arrays.sort()`의 두 번째 인자인 `Comparator`의 역할을 이해하는 데 어려움을 겪었다.
- `Comparator`는 두 원소를 비교하는 기준이며, 실제 정렬은 `sort()`가 수행한다는 것을 배웠다.
- `compareTo()`는 두 문자열을 사전순으로 비교하여 음수, 0, 양수를 반환한다는 것을 알게 되었다.
- `Comparator`가 음수를 반환하면 첫 번째 인자 `a`가 앞에 오도록 정렬한다는 점을 이해했다.
- `sort()`가 비교할 두 원소를 자동으로 전달하며, 비교 순서는 내부 정렬 알고리즘에 의해 결정된다는 것을 배웠다.
- 단순히 숫자를 내림차순으로 정렬하는 것이 아니라, 두 숫자를 이어 붙였을 때 더 큰 값을 만드는 순서로 정렬해야 한다는 것을 알게 되었다.
- `String.valueOf()`를 사용하여 정수를 문자열로 변환하고, `String.join()`으로 문자열 배열을 하나의 문자열로 합치는 방법을 배웠다.
- 구현 과정에서 `Arrays`의 import, 변수명, `compareTo()` 호출 문법, 반환 자료형을 잘못 작성하여 수정했다.
- 모든 숫자가 0인 경우를 고려하여 정렬된 배열의 첫 번째 원소가 `"0"`이면 `"0"`을 반환하도록 예외 처리해야 한다는 점을 배웠다.
