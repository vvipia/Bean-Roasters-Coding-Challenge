# 폰켓몬
---
## 1. 문제 정보
---
- 플랫폼: 프로그래머스
- 난이도: Level 1
- 문제 링크: [폰켓몬](https://school.programmers.co.kr/learn/courses/30/lessons/1845)
- 사용 언어: Java
- 풀이 코드: [P1845.java](./P1845.java)

## 2. 문제 설명
---
주어진 폰켓몬 중 전체 마릿수의 절반을 선택할 때, 서로 다른 종류를 최대 몇 개까지 선택할 수 있는지 구합니다.

## 3. 접근 방법
---
최대한 다양한 종류를 선택하려면 같은 종류를 여러 마리 선택하기보다 서로 다른 종류를 한 마리씩 선택해야 합니다. 따라서 종류별 마릿수를 세지 않고, 서로 다른 종류가 몇 개 있는지만 구했습니다.

1. 전체 마릿수의 절반인 `nums.length / 2`를 선택할 마릿수 `n`에 저장합니다.
2. 배열을 순회하면서 `HashMap`에 종류 번호가 있는지 `containsKey`로 확인합니다.
3. 아직 없는 번호라면 `put`으로 추가하고, 이미 있는 번호라면 넘어갑니다. 값으로 저장하는 `1`은 마릿수가 아니라 해당 종류가 존재한다는 표시입니다.
4. `map.size()`로 서로 다른 종류 수를 구하고, 선택할 마릿수 `n`과 비교해 더 작은 값을 반환합니다.

### 예시
---
폰켓몬 배열이 `[3, 1, 2, 3]`로 주어졌을 때, 종류가 1, 2, 3으로 세 가지지만 두 마리만 선택할 수 있으므로 최대 종류 수는 2입니다.

## 4. 핵심 개념
---

### HashMap으로 중복 종류 제외하기

`HashMap`의 키는 중복될 수 없습니다. 종류 번호를 키로 저장하면 같은 번호가 여러 번 등장해도 하나의 종류로 관리할 수 있고, `size()`는 서로 다른 종류 수가 됩니다.

현재 코드에서는 종류 번호의 존재 여부만 필요하고 값은 사용하지 않습니다. 따라서 중복 원소를 허용하지 않는 `HashSet<Integer>`로도 같은 목적을 더 직접적으로 표현할 수 있습니다. `HashSet`을 사용하면 `containsKey`로 확인하는 대신 `add`로 번호를 추가하고, 마지막에 `size()`로 종류 수를 구합니다.


## 5. 시간·공간 복잡도
---

`N`은 입력 배열 `nums`의 길이이고, `K`는 서로 다른 폰켓몬 종류 수입니다.

- **시간 복잡도: 평균 O(N)** — 배열의 N개 원소를 한 번씩 확인합니다. 해시가 적절히 분산된다는 가정에서 `HashMap`의 조회와 삽입은 평균 O(1)이므로 전체 시간 복잡도는 평균 O(N)입니다.
- **추가 공간 복잡도: O(K), 최악 O(N)** — `HashMap`에 서로 다른 종류마다 하나의 항목을 저장합니다. 모든 폰켓몬의 종류가 다르면 K = N이므로 O(N)의 추가 공간을 사용합니다.
