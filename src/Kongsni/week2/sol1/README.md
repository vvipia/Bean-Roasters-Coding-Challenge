# 가장 큰 수

## 1. 문제 정보

- 플랫폼: 프로그래머스
- 난이도: Level 2
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42746
- 사용 언어: Java

## 2. 문제 설명

0 또는 양의 정수가 담긴 배열에서 숫자들의 순서를 재배치하여 만들 수 있는 가장 큰 수를 구하는 문제입니다.

예를 들어 `[6, 10, 2]`가 주어졌을 때 숫자를 이어 붙여 만들 수 있는 가장 큰 수는 `6210`입니다.

결과가 매우 클 수 있으므로 문자열 형태로 반환해야 합니다.

## 3. 접근 방법

처음에는 숫자를 내림차순으로 정렬하면 된다고 생각할 수 있지만, 단순히 숫자의 크기대로 정렬하면 원하는 결과가 나오지 않습니다.

예를 들어 3과 30은 30이 더 크지만, 이어 붙이면 `330`이 `303`보다 크기 때문에 3이 앞에 와야 합니다.

따라서 두 숫자를 이어 붙인 결과를 비교하는 방식으로 정렬해야 합니다.

1. `numbers` 배열의 정수를 문자열로 변환합니다.
2. `Arrays.sort()`와 Comparator를 이용하여 정렬 기준을 정의합니다.
3. 두 문자열 a, b에 대해 `a + b`와 `b + a`를 비교합니다.
4. 이어 붙인 결과가 더 큰 순서로 정렬합니다.
5. 모든 숫자가 0인 경우에는 `"0"`을 반환합니다.
6. `StringBuilder`로 정렬된 문자열을 이어 붙여 반환합니다.

## 4. 핵심 개념

- **Arrays.sort()**: 배열을 정렬하는 메서드
- **Comparator**: 원하는 기준에 따라 정렬 순서를 정의하는 인터페이스
- **람다 표현식**: 비교 함수를 간결하게 작성하는 문법
- **compareTo()**: 문자열을 사전식으로 비교하는 메서드
- **String.valueOf()**: 정수를 문자열로 변환하는 메서드
- **StringBuilder**: 문자열을 효율적으로 이어 붙이는 클래스

가장 중요한 코드는 다음과 같습니다.

`Arrays.sort(arr, (a, b) -> (b + a).compareTo(a + b));`

예를 들어 a가 `"3"`, b가 `"30"`이라면 다음과 같습니다.

- `a + b = "330"`
- `b + a = "303"`

330이 303보다 크므로 3이 30보다 앞에 오도록 정렬합니다.

## 5. 어려웠던 점

처음에는 숫자를 내림차순으로 정렬하면 가장 큰 수를 만들 수 있다고 생각했지만, 숫자의 자릿수가 서로 다르면 단순한 정렬만으로는 해결할 수 없다는 점이 어려웠습니다.

특히 `Comparator`를 이용하여 정렬 기준을 직접 정의하는 방법이 익숙하지 않았습니다.

`(b + a).compareTo(a + b)`에서 비교하는 순서가 왜 반대로 되어 있는지 이해하는 것이 중요했습니다.

또한 `[0, 0, 0]`과 같은 입력에서는 결과가 `"000"`이 아닌 `"0"`이어야 하므로 예외 처리가 필요하다는 점도 알게 되었습니다.

## 6. 새로 배운 점

- `Arrays.sort()`에서 Comparator를 이용해 정렬 기준을 변경할 수 있다는 것을 배웠습니다.
- 람다 표현식을 사용하여 비교 함수를 간단하게 작성하는 방법을 알게 되었습니다.
- `compareTo()`를 이용한 문자열 비교 방법을 배웠습니다.
- 문자열을 이어 붙이는 순서에 따라 정렬 기준을 설정할 수 있다는 것을 알게 되었습니다.
- `StringBuilder`를 이용하면 반복적인 문자열 연결을 효율적으로 처리할 수 있다는 것을 배웠습니다.
- 정렬 문제에서는 단순한 오름차순과 내림차순뿐만 아니라 문제에 맞는 비교 기준을 찾는 것이 중요하다는 것을 알게 되었습니다.

## 7. 시간 복잡도

- 시간 복잡도: O(N log N)
    - N: numbers 배열의 길이
    - 문자열 변환: O(N)
    - 정렬: O(N log N)
    - 문자열 결합: O(N)
    - 각 숫자는 최대 4자리이므로 문자열 비교 비용은 상수로 취급할 수 있습니다.
- 공간 복잡도: O(N)
    - 문자열 배열과 결과 문자열을 저장하기 위한 공간
