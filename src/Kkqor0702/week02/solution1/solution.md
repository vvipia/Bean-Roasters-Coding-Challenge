# 문제 이름: OX퀴즈

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 문자열 파싱, 구현  
**소요 시간:** 5분?  
**AI 질문:** X

## 1. 문제 요약

문자열 배열 quiz에 담긴 덧셈 또는 뺄셈 수식이 올바른지 판단한다.

- 입력: `["3 - 4 = -3", "5 + 6 = 11"]`
- 출력: `["X", "O"]`
- 주요 조건: 수식이 맞으면 "O", 틀리면 "X"를 반환한다.

## 2. 나의 문제 접근법

1. quiz 길이만큼 결과 배열을 생성한다.
2. 각 수식을 `split(" ")`으로 분리한다.
3. 첫 번째 숫자, 연산자, 두 번째 숫자, 결과를 각각 추출한다.
4. 숫자 문자열은 `Integer.parseInt()`로 정수로 변환한다.
5. 연산자가 "+"이면 덧셈 결과를, "-"이면 뺄셈 결과를 주어진 결과와 비교한다.
6. 비교 결과에 따라 "O" 또는 "X"를 저장하고 다음 인덱스로 이동한다.
7. 모든 수식을 처리한 결과 배열을 반환한다.

## 3. 시간 복잡도

- 문자열 분리 및 정수 변환: 수식 하나당 O (L)
- 덧셈·뺄셈 및 결과 저장: 수식 하나당 O (1)
- 전체 수식 처리: O (N × L)

**최종 시간 복잡도: O (N × L)**  
**공간 복잡도: O (N + L)**

※ N = 수식의 개수
※ L = 수식 하나의 최대 문자열 길이
※ 공간 복잡도에는 결과 배열 O (N)과 현재 수식의 분리 결과 O (L)을 포함한다.
※ 결과 배열을 제외한 보조 공간은 O (L)이다.

## 4. 시행착오 및 배운 점

- `split(" ")`을 이용해 공백으로 구분된 수식을 분리하였다.
- `Integer.parseInt()`로 음수를 포함한 숫자 문자열을 정수로 변환하였다.
- 문자열 연산자 비교에 `equals()`를 사용하였다.
- 덧셈과 뺄셈을 각각 처리하고 계산 결과에 따라 정답 여부를 저장하였다.
- 코드 리뷰에서는 계산 결과를 변수에 저장하면 반복되는 정답 판정 코드를 줄일 수 있음을 확인하였다.
