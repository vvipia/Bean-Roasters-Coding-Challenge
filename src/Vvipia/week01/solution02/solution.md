# 문제 이름: 길이에 따른 연산

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 구현, 수학  
**소요 시간:** 3분  
**AI 질문:** X

## 1. 문제 요약

정수가 담긴 리스트에서 각 정들의 합이 11 이상이면 모두 합, 이하면 곱을 리턴

- 입력: `[3, 4, 5, 2, 5, 4, 6, 7, 3, 7, 2, 2, 1]`
- 출력: `51`

## 2. 나의 문제 접근 법

1. 주어지는 정수 배열의 길이로 조건문을 만든다.
2. 각 조건에 따른 계산법을 적용한다.

## 3. 시간 복잡도
- 입력되는 배열의 길이(N)에 따라 반복 횟수가 달라지므로 시간 복잡도는 O(N)
