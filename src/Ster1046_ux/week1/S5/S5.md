# 문제 이름: 약수 구하기

- **출처:** 프로그래머스
- **난이도:** Lv.0
- **유형:** 반복문, 배열, 수학
- **소요 시간:** 13분 52초
- **AI 질문:** O

## 1. 문제 요약

정수 `n`의 약수를 오름차순으로 담은 정수 배열을 반환한다.

- 입력: `24`
- 출력: `[1, 2, 3, 4, 6, 8, 12, 24]`

## 2. 나의 문제 접근 법

1. 첫 번째 반복문에서 1부터 n까지 확인한다.
2. `n % i == 0`이면 약수이므로 `count`를 증가시킨다.
3. 약수 개수인 `count`만큼 결과 배열 `answer`를 생성한다.
4. 두 번째 반복문에서 약수를 다시 찾는다.
5. 찾은 약수를 `answer[index]`에 저장하고 `index`를 증가시킨다.
6. 완성된 배열을 반환한다.

## 3. 시간 복잡도

- **O(N)** — 1부터 N까지 확인하는 반복문을 두 번 실행한다.
- **공간 복잡도: O(K)** — K는 약수 개수이며, 결과 배열에 K개의 값을 저장한다.

## 4. 시행착오 및 배운 점

- 배열의 크기를 정하기 위해 약수 개수를 먼저 세고, 배열을 만든 뒤 다시 반복하여 값을 채우는 과정에서 헷갈렸다. 
- 개수 계산과 값 저장을 나누어 처리한다는 점을 배웠다.
