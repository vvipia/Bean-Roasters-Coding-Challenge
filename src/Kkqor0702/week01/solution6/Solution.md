# 문제 이름: 폰켓몬

**출처:** 프로그래머스  
**난이도:** Lv.1    
**유형:** 해시  
**소요 시간:** 5분 정도?  
**AI 질문:** X

## 1. 문제 요약

int 배열 하나가 주어진다. 해당 배열에는 중복을 허용하는 값들이 들어있다. 배열 길이의 절반 횟수만큼 뽑았을 때, 몇 종류의 수를 뽑을 수 있을지?

- 입력: `[3,1,2,3]`
- 출력: `2`

## 2. 나의 문제 접근 법

1. 중복을 허용하지 않는 자료 구조가 필요하다 -> `set`
2. int 배열의 값들을 모두 set에 담아준다.
3. 절반만큼 뽑을 수 있으니, 최대값은 len/2
4. 수들의 종류는 set의 사이즈
5. 뽑는 최대 가지의 수는 len/2 를 넘길 수 없고, set의 size (int 배열의 종류 수) 를 넘길 수 없다.

## 3. 시간 복잡도

- O (n)
    - 문제 입력으로 받는 배열을 순회하여 `HashSet` 에 넣어준다

## 4. 시행착오 및 배운 점

- 자바 `Set` 의 종류에는
    - `HashSet`: 정렬 X, 순서 보장 X
    - `LinkedHashSet`: 정렬 X, 순서 보장 O
    - `TreeSet`: 정렬 O, 순서 보장 O

가 있다는 사실을 알게 되었다. 이전에는 `HashSet`만 사용해보았던 것 같다. 이 문제에서는 정렬과 순서가 보장될 필요가 없으니 `HashSet` 을 사용하였다.
