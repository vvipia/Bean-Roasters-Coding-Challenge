# N으로 표현

## 1. 문제 정보

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42895
- 사용 언어: Java

## 2. 문제 설명

숫자 N과 사칙연산을 사용하여 목표 숫자 `number`를 만드는 문제입니다.

같은 숫자 N을 여러 번 사용할 수 있으며, N을 사용하는 횟수가 최소가 되도록 해야 합니다.

N을 8번 이하로 사용하여 목표 숫자를 만들 수 없다면 -1을 반환합니다.

## 3. 접근 방법

처음에는 사칙연산을 이용해 모든 경우를 직접 계산해야 한다고 생각했지만, 숫자를 사용하는 횟수에 따라 결과를 저장하고 재활용하는 동적 계획법(DP)을 이용하면 해결할 수 있다는 것을 알게 되었습니다.

1. `dp[i]`를 숫자 N을 정확히 i번 사용해서 만들 수 있는 숫자들의 집합으로 정의합니다.
2. `HashSet`을 사용하여 중복되는 계산 결과를 제거합니다.
3. N을 이어 붙인 숫자(5, 55, 555 등)를 추가합니다.
4. 이전에 계산한 DP 집합들을 조합하여 사칙연산을 수행합니다.
5. 계산 결과에 목표 숫자가 포함되어 있다면 현재 N의 사용 횟수를 반환합니다.
6. 8번까지 확인해도 목표 숫자를 만들 수 없다면 -1을 반환합니다.

## 4. 핵심 개념

- **동적 계획법(DP)**: 이전에 계산한 결과를 저장하고 재활용하는 알고리즘
- **HashSet**: 중복을 허용하지 않는 자료구조
- **ArrayList**: DP 집합들을 순서대로 관리하기 위한 자료구조
- **중첩 반복문**: 두 DP 집합의 모든 숫자 조합을 확인하는 방법
- **정수 나눗셈**: Java에서 정수끼리 나누면 소수점 이하를 버립니다.

특히 `dp[4]`를 계산할 때 다음과 같이 이전 결과를 조합할 수 있습니다.

- `dp[1]`과 `dp[3]`
- `dp[2]`와 `dp[2]`
- `dp[3]`과 `dp[1]`

## 5. 어려웠던 점

숫자 N을 여러 번 사용해서 만들 수 있는 모든 경우를 어떻게 확인해야 하는지가 어려웠습니다.

특히 사칙연산뿐만 아니라 괄호를 사용하는 경우까지 고려해야 하기 때문에 단순한 반복문으로 해결하기 어렵다고 느꼈습니다.

DP를 이용하면 숫자를 사용한 횟수별로 결과를 저장하고, 이전 결과를 조합하여 새로운 결과를 만들 수 있다는 점을 이해하는 것이 중요했습니다.

또한 뺄셈과 나눗셈은 계산 순서에 따라 결과가 달라지므로 두 집합의 순서를 모두 고려해야 한다는 점도 알게 되었습니다.

## 6. 새로 배운 점

- DP를 활용하여 이전 계산 결과를 재사용하는 방법을 배웠습니다.
- `HashSet`으로 중복된 계산 결과를 제거할 수 있다는 것을 알게 되었습니다.
- `List<Set<Integer>>`를 이용하여 여러 개의 집합을 관리하는 방법을 배웠습니다.
- 숫자를 이어 붙일 때 `repeated = repeated * 10 + N`을 사용할 수 있다는 것을 알게 되었습니다.
- 복잡한 수식을 작은 문제로 나누어 해결하는 방법을 배웠습니다.

## 7. 시간 복잡도

- 시간 복잡도: 각 DP 집합의 크기에 따라 달라집니다.
    - i번째 단계에서는 `dp[j]`와 `dp[i-j]`의 모든 원소 조합을 확인합니다.
    - N의 사용 횟수가 최대 8번으로 제한되어 있습니다.
- 공간 복잡도: O(S)
    - S: DP 집합들에 저장되는 서로 다른 숫자의 총개수
