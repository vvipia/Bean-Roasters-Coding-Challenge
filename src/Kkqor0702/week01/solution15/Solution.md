# 문제 이름: 최빈값 구하기

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 배열, 구현, 빈도수 계산  
**소요 시간:** 10 ?  
**AI 질문:** X (최초 풀이 기준)

## 1. 문제 요약

정수 배열에서 가장 자주 등장하는 값 (최빈값)을 반환하는 문제.

최빈값이 여러 개 존재한다면 -1을 반환한다.

- 입력: `[1, 2, 3, 3, 3, 4, 4]`
- 출력: `3`

## 2. 나의 문제 접근법

1. 입력값의 범위가 0 이상 1000 미만이므로 크기가 1000인 배열을 생성한다.
2. 입력 배열을 순회하면서 각 숫자를 인덱스로 사용하여 등장 횟수를 증가시킨다.
3. `Arrays.stream(arr).max()`를 사용하여 가장 높은 등장 횟수를 구한다.
4. 빈도수 배열을 순회하면서 최대 등장 횟수와 일치하는 숫자를 찾는다.
5. 일치하는 숫자가 하나라면 해당 인덱스를 반환한다.
6. 최대 등장 횟수를 가진 숫자가 여러 개라면 -1을 반환한다.

## 3. 시간 복잡도

- 입력 배열 순회: O (N)
- 빈도수 배열의 최댓값 탐색: O (K)
- 최빈값 중복 확인: O (K)

**최종 시간 복잡도: O (N + K)**  
**공간 복잡도: O (K)**

※ N = 입력 배열의 길이
※ K = 빈도수 배열의 크기 (1000)

K가 고정된 상수이므로 입력 크기 N을 기준으로
시간 복잡도는 O (N), 공간 복잡도는 O (1)로 볼 수 있다.

## 4. 시행착오 및 배운 점

- 배열의 인덱스를 숫자 자체로 활용하여 등장 횟수를 계산하였다.
- `Arrays.stream().max().orElse()`를 이용해 배열의 최댓값을 구하였다.
- 최빈값이 여러 개 존재하는 경우를 처리하기 위해 최대 빈도수의 개수를 계산하였다.
- 숫자의 범위가 정해져 있다면 HashMap 대신 배열로 빈도수를 관리할 수 있다.
- 최댓값 계산과 최빈값 중복 확인을 하나의 반복문으로 합칠 수 있다.

- Map 을 사용해서 해보려고 했지만 구현에서 막혔었음

알게된 문법

- `Map.Entry` -> Map에 저장된 Key-Value 한 쌍을 나타낸 인터페이스
    - 즉, Entry 하나를 가져오면 Key 와 Value에 모두 접근 가능
- `Map.entrySet()` -> Map에 저장된 모든 Key-Value 쌍을 Set 형태로 반환하는 함수
    - => Set<Map.Entry<Integer, Integer>> 형태로 반복문 순회시 `Map.Entry` 의 형태로 접근 가능
