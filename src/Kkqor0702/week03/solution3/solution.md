# 문제 이름: 모의고사

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 배열, 완전 탐색, 구현, 시뮬레이션  
**소요 시간:** ?  
**AI 질문:** X

## 1. 문제 요약

세 명의 수포자가 각각 정해진 규칙에 따라 문제를 찍을 때,
정답 배열 `answers`와 비교하여 가장 많은 문제를 맞힌 사람을 반환하는 문제.

최고 점수가 같은 사람이 여러 명이라면 오름차순으로 반환한다.

- 1번 수포자: `1, 2, 3, 4, 5` 반복
- 2번 수포자: `2, 1, 2, 3, 2, 4, 2, 5` 반복
- 3번 수포자: `3, 3, 1, 1, 2, 2, 4, 4, 5, 5` 반복

- 입력: `answers = [1, 2, 3, 4, 5]`
- 출력: `[1]`

## 2. 나의 문제 접근법

1. 세 수포자의 반복되는 정답 패턴을 각각 배열로 정의한다.
2. 각 수포자가 맞힌 문제의 수를 저장할 `score1`, `score2`, `score3` 변수를 선언한다.
3. `answers` 배열을 순회하면서 각 수포자의 정답 패턴과 비교한다.
4. `%` 연산자를 사용하여 패턴 배열의 인덱스를 순환시킨다.
    - `st1[i % st1.length]`
    - `st2[i % st2.length]`
    - `st3[i % st3.length]`
5. 정답과 일치하면 해당 수포자의 점수를 1 증가시킨다.
6. `Math.max()`를 중첩하여 세 수포자의 점수 중 최댓값을 구한다.
7. 최고 점수를 받은 수포자의 수를 계산하여 반환할 배열의 크기를 결정한다.
8. 수포자 1번부터 3번까지 순서대로 최고 점수와 비교하여 결과 배열에 추가한다.
9. 최고 점수를 받은 수포자들의 번호가 담긴 배열을 반환한다.

## 3. 시간 복잡도

- 세 수포자의 패턴 배열 생성: O (1)
- `answers` 배열 순회: O (N)
    - 각 문제마다 세 수포자의 답 비교: O (1)
- 최고 점수 계산: O (1)
- 최고 점수를 받은 수포자 확인 및 결과 배열 생성: O (1)

**최종 시간 복잡도: O (N)**  
**공간 복잡도: O (1)**

※ N은 `answers` 배열의 길이이다.
※ 수포자의 수와 정답 패턴의 길이가 고정되어 있고,
반환 배열의 최대 크기도 3이므로 추가 공간 복잡도는 O (1)이다.

## 4. 시행착오 및 배운 점

- 반복되는 정답 패턴을 배열로 정의하여 관리하였다.
- `%` 연산자를 활용하면 패턴 배열의 길이를 넘어가는 인덱스를 처음부터 다시 순환시킬 수 있다.
    - `i % pattern.length`
- `Math.max()`를 중첩하여 세 숫자의 최댓값을 구할 수 있다.
- 최고 점수가 같은 사람이 여러 명일 수 있으므로 각각 독립적인 `if`문으로 검사하였다.
- 결과 배열의 크기를 미리 알기 위해 최고 점수를 받은 수포자의 수를 먼저 계산하였다.
- 배열에 값을 추가하면서 `index++`를 활용하여 다음 저장 위치로 이동하였다.
- 점수와 정답 패턴을 각각 배열로 관리하면 중복된 코드를 줄일 수 있다.
- 결과의 개수를 미리 알기 어려울 때는 `ArrayList`를 사용한 뒤 배열로 변환하는 방법도 고려할 수 있다.
