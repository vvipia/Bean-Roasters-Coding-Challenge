# 문제 이름: 외계어 사전

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** ?  
**소요 시간:** ?  
**AI 질문:** X

## 1. 문제 요약

String 배열 2개, 첫번째 spell 배열의 원소들은 모두 한 글자
이 글자들을 모두 한 번씩만 포함하는 String 이 두 번째 배열 dic 에 존재하나

- 입력: `["z", "d", "x"]`, `["def", "dww", "dzx", "loveaw"]`
- 출력: `1`

## 2. 나의 문제 접근 법

1. dic 배열의 원소들 조사
2. 해당 원소 (문자열) 이 spell 배열을 모두 한 번씩 포함하면 됨
3. spell 배열의 길이? -> len
4. 일치할 때마다 count 를 1씩 증가시켜주고, spell 배열의 원소가 dic 원소에 없다면 후보 탈락
5. len == count 이면서 중간에 탈락하지 않았다면 조건 만족 ! -> return 1

## 3. 시간 복잡도

- O (n^2)

## 4. 시행착오 및 배운 점

- 처음에는 `boolean` 으로 해서 false / true 로 바꾸는 식으로 구현했다가, 뒤늦게 문제에 한 번씩만 포함해야 한다는 말을 발견했다. 예시의 입력에서 zzdx 는 원하는 조건으로 충족하지 않는 것
  같다.
  근데 이상하게 boolean으로 했는데도 채점을 통과했다. 그래도 문제에 해당하는 방법으로 바꾸어 보았다.
