# 문제 이름: 제일 작은 수 제거하기

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 구현  
**소요 시간:** 11분  
**AI 질문:** X

## 1. 문제 요약

주어진 배열에서 제일 작은 수만 제거하고 리턴
- 입력: `[1,1,3,3,0,1,1]`
- 출력: `[1,3,0,1]`

## 2. 나의 문제 접근 법
1. 배열의 값을 반복문으로 확인하면서 제일 작은 수의 인덱스를 저장
2. 새로운 배열에 해당 인덱스만 제외하고 배열 생

## 3. 시간 복잡도
- O(N)

## 4. 시행착오 및 배운 점
- 없음
