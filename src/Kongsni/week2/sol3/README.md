# 조이스틱

## 1. 문제 정보

- 플랫폼: 프로그래머스
- 난이도: Level 2
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42860
- 사용 언어: Java

## 2. 문제 설명

조이스틱을 이용하여 처음에 A로만 이루어진 문자열을 원하는 알파벳 이름으로 변경하는 문제입니다.

조이스틱은 상하좌우로 이동할 수 있으며, 각 방향으로 움직일 때마다 조작 횟수가 1씩 증가합니다.

상하 이동으로 알파벳을 변경하고, 좌우 이동으로 커서 위치를 변경할 수 있습니다.

이때 원하는 이름을 완성하기 위한 최소 조작 횟수를 구해야 합니다.

## 3. 접근 방법

문제를 상하 이동과 좌우 이동으로 나누어 생각했습니다.

상하 이동은 각 알파벳을 A에서 변경하는 최소 횟수를 구하면 되지만, 좌우 이동은 연속된 A의 위치에 따라 이동 경로가 달라질 수 있습니다.

1. 문자열을 순회하면서 각 알파벳을 변경하는 최소 상하 이동 횟수를 계산합니다.
2. 위로 이동하는 경우와 아래로 이동하는 경우 중 작은 값을 선택합니다.
3. 좌우 이동의 기본값을 `name.length() - 1`로 설정합니다.
4. 문자열에서 연속된 A 구간을 찾습니다.
5. 오른쪽으로 이동하다가 왼쪽으로 돌아오는 경우를 계산합니다.
6. 왼쪽으로 이동하다가 오른쪽으로 돌아오는 경우도 계산합니다.
7. 두 이동 방법과 기본 이동 방법 중 최솟값을 선택합니다.
8. 상하 이동 횟수와 좌우 이동 횟수를 더하여 반환합니다.

## 4. 핵심 개념

- **그리디 알고리즘(Greedy)**: 각 상황에서 적절한 선택을 통해 최적의 결과를 구하는 알고리즘
- **String.charAt()**: 문자열의 특정 인덱스에 있는 문자를 가져오는 메서드
- **Math.min()**: 두 값 중 작은 값을 반환하는 메서드
- **문자 연산**: Java에서 문자끼리 빼면 문자 코드값의 차이를 계산할 수 있습니다.
- **문자열 순회**: 반복문을 이용하여 문자열의 각 문자를 확인하는 방법

상하 이동 횟수는 다음과 같이 계산합니다.

`Math.min(c - 'A', 'Z' - c + 1)`

예를 들어 J를 만드는 경우:

- 위로 이동: 9번
- 아래로 이동: 17번
- 최소 이동: 9번

좌우 이동에서는 연속된 A 구간을 건너뛰는 것이 중요합니다.

오른쪽으로 이동하다가 돌아오는 경우:

`i * 2 + length - next`

왼쪽으로 이동하다가 돌아오는 경우:

`i + (length - next) * 2`

여기서 `i`는 현재 위치이고, `next`는 현재 위치 이후 연속된 A 구간이 끝나는 인덱스입니다.

## 5. 어려웠던 점

상하 이동은 각 알파벳의 위치를 계산하면 되기 때문에 비교적 이해하기 쉬웠지만, 좌우 이동의 최소 횟수를 구하는 과정이 어려웠습니다.

처음에는 오른쪽으로만 이동하거나 왼쪽으로만 이동하면 된다고 생각할 수 있지만, 문자열 중간에 A가 연속해서 등장하면 방향을 바꾸는 것이 더 효율적일 수 있다는 점을 알게 되었습니다.

특히 오른쪽으로 이동하다가 돌아오는 경우와 왼쪽으로 이동하다가 돌아오는 경우를 모두 고려해야 한다는 점이 중요했습니다.

또한 연속된 A 구간을 찾기 위해 `while`문을 사용하는 부분과 좌우 이동 횟수를 계산하는 공식을 이해하는 것이 어려웠습니다.

## 6. 새로 배운 점

- 그리디 알고리즘을 이용하여 최소 이동 횟수를 구하는 방법을 배웠습니다.
- `charAt()`을 이용해 문자열의 특정 문자를 가져오는 방법을 복습했습니다.
- 문자 간의 뺄셈으로 알파벳 사이의 거리를 계산할 수 있다는 것을 알게 되었습니다.
- `Math.min()`을 이용하여 여러 이동 방법 중 최솟값을 선택하는 방법을 배웠습니다.
- 연속된 A 구간을 찾아 불필요한 커서 이동을 줄일 수 있다는 것을 알게 되었습니다.
- 단순히 한 방향으로 이동하는 것보다 방향을 바꾸는 경우까지 고려해야 최솟값을 구할 수 있다는 것을 배웠습니다.

## 7. 시간 복잡도

- 시간 복잡도: O(N²)
    - N: name 문자열의 길이
    - 상하 이동 계산: O(N)
    - 연속된 A 구간 탐색: 최악의 경우 O(N²)
    - 각 위치에서 `while`문으로 A 구간을 탐색하기 때문입니다.
- 공간 복잡도: O(1)
    - 문자열 길이와 관계없이 일정한 크기의 변수만 사용합니다.
