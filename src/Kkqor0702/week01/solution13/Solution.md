# 문제 이름: 배열 조각하기

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 배열, 구현, 시뮬레이션  
**소요 시간:** 5분?  
**AI 질문:** X (최초 풀이 기준)

## 1. 문제 요약

정수 배열 arr과 query가 주어진다.

query를 순서대로 순회하면서 다음 조건에 따라 배열을 자른다.

- 짝수 인덱스: query[i] 인덱스 이후의 원소를 제거한다.
- 홀수 인덱스: query[i] 인덱스 이전의 원소를 제거한다.

이 과정을 모두 수행한 후 남은 배열을 반환한다.

- 입력: `arr = [0, 1, 2, 3, 4, 5], query = [4, 1, 2]`
- 출력: `[1, 2, 3]`

## 2. 나의 문제 접근법

1. arr 배열을 answer 변수에 할당한다.
2. query 배열을 순회하면서 인덱스의 홀짝 여부를 확인한다.
3. 짝수 인덱스라면 `Arrays.copyOf()`를 사용하여
   query[i] 인덱스까지의 원소를 복사한다.
4. 홀수 인덱스라면 `Arrays.copyOfRange()`를 사용하여
   query[i] 인덱스부터 마지막 원소까지 복사한다.
5. 매 반복마다 잘라낸 배열을 answer에 다시 할당한다.
6. 모든 query를 처리한 후 answer를 반환한다.

## 3. 시간 복잡도

- query 배열 순회: O (Q)
- 배열 복사: 최악 O (N)
- 각 query마다 새로운 배열을 생성하므로 최악 O (Q × N)

**최종 시간 복잡도: O (Q × N)**  
**공간 복잡도: O (N)**

※ N = arr 배열의 길이
※ Q = query 배열의 길이

## 4. 시행착오 및 배운 점

- `Arrays.copyOf()`를 사용하면 배열의 앞부분을 원하는 길이만큼 복사할 수 있다.
- `Arrays.copyOfRange()`를 사용하면 원하는 시작 인덱스부터 끝 인덱스 직전까지 복사할 수 있다.
- `Arrays.copyOfRange()`의 종료 인덱스는 포함되지 않는다는 점에 주의해야 한다.
- 매 반복마다 새로운 배열을 생성하기 때문에 불필요한 복사 비용이 발생할 수 있다.
- 배열을 직접 자르지 않고 시작 인덱스와 끝 인덱스만 관리하면 시간 복잡도를 개선할 수 있다.
