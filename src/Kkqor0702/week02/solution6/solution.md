# 문제 이름: 분수의 덧셈

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 수학, 최대공약수, 유클리드 호제법  
**소요 시간:** ?  
**AI 질문:** O
- 유클리드 호제법

## 1. 문제 요약

두 분수를 더한 결과를 기약분수로 나타내고, 분자와 분모를 배열에 담아 반환한다.

- 입력: `numer1 = 1, denom1 = 2, numer2 = 3, denom2 = 4`
- 출력: `[5, 4]`
- 주요 조건: 결과의 분자와 분모는 공약수가 1인 상태여야 한다.

## 2. 나의 문제 접근법

1. 두 분모의 곱을 공통 분모로 사용한다.
2. 각 분자에 상대 분모를 곱한 뒤 더하여 결과 분자를 구한다.
3. 유클리드 호제법으로 결과 분자와 분모의 최대공약수를 구한다.
4. 분자와 분모를 각각 최대공약수로 나누어 약분한다.
5. 약분한 분자와 분모를 배열에 저장하여 반환한다.

## 3. 시간 복잡도

- 통분을 위한 곱셈과 덧셈: O (1)
- 최대공약수 계산: O (log M)
- 약분 및 결과 저장: O (1)

**최종 시간 복잡도: O (log M)**  
**공간 복잡도: O (1)**

※ M = 통분한 분자와 분모 중 작은 값
※ 최대공약수를 두 번 계산하지만 상수 배이므로 최종 복잡도는 같다.
※ 반복문으로 구현하여 재귀 호출에 필요한 공간이 없다.

## 4. 시행착오 및 배운 점

- 분모의 곱을 공통 분모로 사용하여 두 분수를 더하였다.
- 분자와 분모를 최대공약수로 나누면 기약분수로 만들 수 있다.
- 유클리드 호제법은 gcd (a, b) = gcd (b, a % b) 관계를 이용한다.
- 나머지가 0이 되었을 때 마지막으로 남은 a가 최대공약수이다.
- 유클리드 호제법으로 최대공약수를 구하는 공식을 다시 한 번 찾아보았다.
