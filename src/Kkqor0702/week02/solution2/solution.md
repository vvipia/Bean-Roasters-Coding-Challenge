# 문제 이름: 다음에 올 숫자

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 수학, 배열, 구현  
**소요 시간:** 2분?  
**AI 질문:** X

## 1. 문제 요약

등차수열 또는 등비수열인 common 배열에서 마지막 원소 다음에 올 숫자를 반환한다.

- 입력: `[1, 2, 3, 4]`
- 출력: `5`
- 입력: `[2, 4, 8]`
- 출력: `16`

## 2. 나의 문제 접근법

1. 첫 번째와 두 번째 원소의 차이, 두 번째와 세 번째 원소의 차이를 비교한다.
2. 두 차이가 같으면 등차수열로 판단하고 공차를 num에 저장한다.
3. 다르면 등비수열로 판단하고 공비를 num에 저장한다.
4. isMul 변수로 등비수열 여부를 저장한다.
5. 등비수열이면 마지막 원소에 공비를 곱하고, 등차수열이면 공차를 더해 반환한다.

## 3. 시간 복잡도

- 등차수열 여부 판단: O (1)
- 공차 또는 공비 계산: O (1)
- 다음 원소 계산: O (1)

**최종 시간 복잡도: O (1)**  
**공간 복잡도: O (1)**

※ 배열 길이와 관계없이 고정된 개수의 원소만 참조한다.

## 4. 시행착오 및 배운 점

- 인접한 원소의 차이를 비교하여 등차수열 여부를 판단하였다.
- 등차수열은 공차를 더하고, 등비수열은 공비를 곱해 다음 원소를 계산하였다.
- 삼항 연산자로 수열의 종류에 따라 반환값을 선택하였다.
- 코드 리뷰에서는 각 분기에서 바로 반환하면 별도의 boolean 변수를 생략할 수 있음을 확인하였다.
