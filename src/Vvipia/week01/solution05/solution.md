# 문제 이름: 완주하지 못한 선수

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 해시
**소요 시간:** 29분  
**AI 질문:** X

## 1. 문제 요약

마라톤 참가 인원 명단과 완주 인원 명단이 주어 졌을 때 완주하지 못한 선수를 구하는 방법 

- 입력: `participant : ["leo", "kiki", "eden"]	completion : ["eden", "kiki"]`
- 출력: `leo`

## 2. 나의 문제 접근 법
### 첫 번째 풀이
1. 리스트의 remove 이용을 위해서 포 문을 통해 배열을 리스트로 변환
2. 완주 선수 목록을 포 문으로 받으면서 리스트에서 해당 인원을 삭제
3. 그 후 남아있는 리스트의 값을 반환

### 두 번째 풀이
1. 해시맵을 이용해 키에다간 이름 벨류에다가 중복된 횟수를 저장 
2. 벨류가 0인 키 값만 찾아 값을 반환

## 3. 시간 복잡도
- 첫 번째 풀이는 remove의 경우 내부적으로 순환을 돌면서 제거할 값을 찾기 때문에 최악의 경우 O(N^2)이 된다.
- 두 번째 풀이는 배열 길이 만큼 반복문이 반복 되므로 시간 복잡도는 O(N)

## 4. 시행착오 및 배운 점
- 첫 번째 리스트를 이용한 풀이로 금방 해결했지만, 효율성 테스트에서 통과하지 못하였다.
- 리스트의 remove의 경우 제거 대상을 순환하며 찾기 때문에 반복문안에서 활용하는 경우 시간 복잡도가 N*N이 된다.
