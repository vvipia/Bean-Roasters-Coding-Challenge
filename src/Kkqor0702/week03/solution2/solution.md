# 문제 이름: 평행

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 수학, 기하학, 구현, 기울기 비교  
**소요 시간:** ?  
**AI 질문:** X

## 1. 문제 요약

2차원 평면 위에 서로 다른 네 점이 주어졌을 때, 네 점을 두 개씩 짝지어 만든 두 직선이 서로 평행한 경우가 존재하면 1, 그렇지 않으면 0을 반환하는 문제.

- 입력: `dots = [[1, 4], [9, 2], [3, 8], [11, 6]]`
- 출력: `1`
- 주요 조건: 네 점을 중복 사용하지 않고 두 쌍으로 나누어 평행 여부를 판단해야 한다.

## 2. 나의 문제 접근법

1. 네 점으로 만들 수 있는 선분의 개수가 6개라고 판단하였다.
2. 각 선분의 기울기를 저장하기 위해 크기가 6인 `double` 배열을 생성하였다.
3. 두 점의 좌표 차이를 나누어 각 선분의 기울기에 대응하는 값을 계산하였다.
4. 계산된 6개의 값을 이중 반복문으로 비교하였다.
5. 서로 다른 배열 인덱스에서 같은 값이 발견되면 평행한 선분이 존재한다고 판단하여 1을 반환하였다.
6. 같은 값이 발견되지 않으면 0을 반환하였다.

## 3. 시간 복잡도

- 6개의 선분에 대한 기울기 계산: O (1)
- 이중 반복문으로 기울기 비교: O (6 × 6) = O (1)

**최종 시간 복잡도: O (1)**  
**공간 복잡도: O (1)**

※ 점의 개수가 4개로 고정되어 있으므로 반복 횟수와 배열 크기는 입력에 관계없이 일정하다.

## 4. 시행착오 및 배운 점

- 처음에는 네 점으로 만들 수 있는 모든 선분의 기울기를 구한 뒤, 같은 기울기가 존재하는지 확인하려고 하였다.
- 하지만 단순히 6개의 기울기를 모두 비교하면 하나의 점을 공유하는 두 선분까지 비교하게 되는 문제가 있었다.
- 문제에서 요구하는 것은 네 점을 중복 없이 두 쌍으로 나누어 만든 두 직선의 평행 여부라는 점을 알게 되었다.
- 네 점을 두 쌍으로 나누는 경우는 총 3가지이다.
    - 0번–1번 / 2번–3번
    - 0번–2번 / 1번–3번
    - 0번–3번 / 1번–2번
- 처음 작성한 코드에서는 일반적인 기울기 `Δy / Δx` 대신 `Δx / Δy`를 계산하였다.
- `double`을 이용한 나눗셈은 0으로 나누는 경우와 부동소수점 오차를 고려해야 한다는 점을 배웠다.
- 기울기를 나눗셈으로 계산하지 않고 교차 곱셈으로 비교할 수 있다는 점을 알게 되었다.
    - 두 선분의 좌표 차이를 각각 `(dx1, dy1)`, `(dx2, dy2)`라고 할 때,
    - `dy1 * dx2 == dy2 * dx1`이면 두 직선은 평행하다.
- 모든 경우를 무조건 비교하기보다 문제에서 실제로 요구하는 조합을 먼저 파악하는 것이 중요하다는 점을 배웠다.
