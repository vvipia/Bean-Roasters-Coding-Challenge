# 같은 숫자는 싫어

## 1. 문제 정보
- 플랫폼: 프로그래머스
- 난이도: Level 1
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12906
- 사용 언어: Java

## 2. 문제 설명
배열에서 연속으로 등장하는 같은 숫자를 하나만 남기고 제거하는 문제입니다.

단, 원래 배열의 순서를 유지해야 합니다.

## 3. 접근 방법
모든 중복을 제거하는 것이 아니라 연속으로 등장하는 중복만 제거해야 한다는 점에 집중했습니다.

1. 결과를 저장할 `ArrayList`를 생성합니다.
2. 반복문으로 배열의 원소를 순서대로 확인합니다.
3. 첫 번째 원소는 무조건 추가합니다.
4. 이후 원소는 바로 앞 원소와 비교해 다를 경우에만 추가합니다.
5. 결과 리스트를 `int[]` 배열로 변환해 반환합니다.

## 4. 핵심 개념
- `ArrayList`: 크기를 동적으로 변경할 수 있는 리스트
- `add()`: 리스트에 원소를 추가하는 메서드
- `arr[i - 1]`: 현재 원소 바로 앞에 있는 원소
- `stream()`: 리스트의 데이터를 순서대로 처리하는 기능
- `mapToInt()`: 값을 기본형 `int`로 변환하는 기능
- `toArray()`: 처리한 데이터를 배열로 변환하는 메서드

## 5. 어려웠던 점
처음에는 중복을 제거하는 문제라서 `HashSet`을 사용할 수 있을 것이라고 생각했습니다.

하지만 이 문제는 연속된 숫자만 제거해야 하기 때문에 `HashSet`을 사용하면 필요한 숫자까지 제거될 수 있다는 점을 알게 되었습니다.

또한 `ArrayList<Integer>`와 `int[]`가 서로 다른 자료형이기 때문에 변환 과정이 필요하다는 점이 어려웠습니다.

## 6. 새로 배운 점
- 모든 중복 제거와 연속 중복 제거는 서로 다르다는 것을 배웠습니다.
- 현재 원소와 바로 앞 원소를 비교하는 방식으로 문제를 해결할 수 있다는 것을 알게 되었습니다.
- `ArrayList`를 `int[]` 배열로 변환하는 방법을 배웠습니다.
- 스택의 LIFO와 큐의 FIFO 개념, `push()`, `pop()`, `offer()`, `poll()` 메서드를 복습했습니다.

## 7. 시간 복잡도
- 시간 복잡도: O(N)
- 공간 복잡도: O(N)
