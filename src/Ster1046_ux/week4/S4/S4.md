## 문제 요약

세 사람이 각자의 규칙을 반복하며 답을 찍습니다.

| 사람 | 반복 규칙                      |
|------|--------------------------------|
| 1번  | `1, 2, 3, 4, 5`                |
| 2번  | `2, 1, 2, 3, 2, 4, 2, 5`       |
| 3번  | `3, 3, 1, 1, 2, 2, 4, 4, 5, 5` |

정답 배열 `answers`가 주어질 때, 가장 많이 맞힌 사람의 번호를 반환합니다.

공동 1등이면 해당하는 사람을 모두 번호가 작은 순서대로 반환합니다.

| answers           | 반환값      |
|-------------------|-------------|
| `[1, 2, 3, 4, 5]` | `[1]`       |
| `[1, 3, 2, 4, 2]` | `[1, 2, 3]` |

## 접근법

### 1. 반복 규칙과 정답 비교하기

각 사람의 규칙을 배열에 저장하고, 모든 문제의 정답과 비교합니다.

규칙 배열은 정답 배열보다 짧을 수 있으므로 나머지 연산 `%`를 사용해 반복할 위치를 구합니다.

```java
pattern1[i % pattern1.length]
```

예를 들어 1번 사람의 규칙 길이는 5입니다.

- 6번째 문제: `i = 5` → `5 % 5 = 0` → `pattern1[0]`
- 10번째 문제: `i = 9` → `9 % 5 = 4` → `pattern1[4]`

찍은 답과 실제 정답이 같으면 해당 사람의 점수를 1 올립니다.

### 2. 최고 점수 구하기

`Math.max()`는 두 값 중 큰 값을 반환합니다.

세 사람의 점수를 비교하려면 두 번 사용합니다.

```java
int maxScore = Math.max(Math.max(score1, score2), score3);
```

### 3. 공동 1등 수만큼 결과 배열 만들기

Java 배열은 만든 뒤 길이를 늘릴 수 없습니다.

따라서 최고 점수와 같은 사람이 몇 명인지 먼저 세고, 필요한 크기의 배열을 만듭니다.

```java
answer = new int[count];
```

### 4. 사람 번호 저장하기

최고 점수와 같은 사람의 번호를 결과 배열에 넣습니다.

- `count`: 공동 1등의 수이자 결과 배열의 길이
- `index`: 다음 사람 번호를 저장할 위치

1번부터 3번까지 차례대로 확인하므로 별도 정렬 없이 오름차순으로 저장됩니다.

공동 1등을 모두 확인해야 하므로 `else if`가 아닌 각각의 `if`를 사용합니다.


프로그래머스 제출 시에는 `public class S4`를 `class Solution`으로 변경합니다.

## 시간 복잡도

- 시간 복잡도: **O(n)**
    - 문제 수가 n개일 때 세 사람이 각각 n개의 답을 확인합니다.
    - 총 비교 횟수는 `3n`이므로 O(n)입니다.
- 공간 복잡도: **O(1)**
    - 규칙 배열의 길이는 고정되어 있습니다.
    - 결과 배열도 최대 3칸이며, 추가 변수의 개수도 일정합니다.

## 시행착오 및 배운 점

### 1. 반복되는 답안의 위치 구하기

처음에는 다음처럼 비교하려고 했습니다.

```java
pattern[i] == answers[i]
```

하지만 문제 수가 규칙 배열의 길이보다 많으면 배열 범위를 벗어납니다.

```java
pattern[i % pattern.length] == answers[i]
```

나머지 연산을 사용하면 규칙 배열의 처음으로 돌아가며 반복할 수 있다는 점을 배웠습니다.

### 2. 배열 이름과 길이를 함께 맞추기

2번 사람의 점수를 구할 때 배열 이름을 바꾸지 않은 부분이 있었습니다.

```java
pattern[i % pattern2.length]
```

2번 사람의 답을 확인하려면 배열과 길이 모두 `pattern2`를 기준으로 사용해야 합니다.

```java
pattern2[i % pattern2.length]
```

### 3. 세 점수의 최댓값 구하기

처음에는 세 값을 한 번에 넣을 수 있는지 질문했습니다.

```java
Math.max(score1, score2, score3)
```

`Math.max()`는 두 값만 비교하므로, 두 번 호출해서 세 점수의 최댓값을 구했습니다.

```java
Math.max(Math.max(score1, score2), score3)
```

### 4. 점수와 사람 번호 구분하기

최고 점수인 사람을 찾는 것과 결과에 넣을 값을 구분해야 했습니다.

반환하는 것은 점수가 아니라 사람 번호입니다. 예를 들어 1번과 2번이 공동 1등이면 `[1, 2]`를 반환합니다.
