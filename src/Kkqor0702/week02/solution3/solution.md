# 문제 이름: 연속된 수의 합

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 수학, 배열, 구현  
**소요 시간:** 2분?  
**AI 질문:** X

## 1. 문제 요약

연속된 정수 num개의 합이 total이 되도록 배열을 만들어 반환한다.

- 입력: `num = 3, total = 12`
- 출력: `[3, 4, 5]`
- 입력: `num = 4, total = 14`
- 출력: `[2, 3, 4, 5]`

## 2. 나의 문제 접근법

1. num 길이의 결과 배열을 생성한다.
2. num의 홀짝에 따라 첫 번째 정수를 계산한다.
3. 홀수라면 중앙값이 total / num이므로, 여기서 num / 2를 뺀다.
4. 짝수라면 total / num에서 num / 2를 빼고 1을 더한다.
5. 첫 번째 정수부터 값을 하나씩 증가시키며 배열에 저장한다.
6. 완성한 배열을 반환한다.

## 3. 시간 복잡도

- 첫 번째 정수 계산: O (1)
- 결과 배열 채우기: O (N)

**최종 시간 복잡도: O (N)**  
**공간 복잡도: O (N)**

※ N = num, 반환할 정수의 개수
※ 결과 배열을 제외한 보조 공간은 O (1)이다.

## 4. 시행착오 및 배운 점

- 연속된 정수의 평균을 이용해 첫 번째 정수를 계산하였다.
- 원소 개수가 홀수인 경우와 짝수인 경우를 구분하여 구현하였다.
- 정수 나눗셈을 이용해 짝수 개수일 때의 시작값을 계산하였다.
- `first++`는 현재 값을 배열에 저장한 뒤 first를 1 증가시킨다.
- 코드 리뷰에서는 연속된 수의 합 공식을 이용하면 홀짝 분기를 합칠 수 있음을 확인하였다.
