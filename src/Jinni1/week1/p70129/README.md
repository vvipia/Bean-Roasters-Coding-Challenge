# 이진 변환 반복하기
---
## 1. 문제 정보
---
- 플랫폼: 프로그래머스
- 난이도: Level 2
- 문제 링크: [이진 변환 반복하기](https://school.programmers.co.kr/learn/courses/30/lessons/70129)
- 사용 언어: Java
- 풀이 코드: [P70129.java](./P70129.java)

## 2. 문제 설명
---
0과 1로 이루어진 문자열에서 모든 0을 제거한 뒤, 남은 문자열의 길이를 이진법으로 표현합니다. 이 과정을 문자열이 `"1"`이 될 때까지 반복하고, 총 변환 횟수와 제거한 0의 개수를 반환합니다.

## 3. 접근 방법
---
0을 제거한 문자열의 길이는 원래 문자열에 포함된 1의 개수와 같습니다. 따라서 1의 개수만 알면 다음 이진 변환에 사용할 값을 구할 수 있습니다.

문제에서 요구하는 것은 변환 횟수와 제거한 0의 개수이므로, 매번 실제 이진 문자열을 만들 필요는 없습니다. 길이를 나타내는 정수를 2로 나누면서 이진 표현의 1과 0 개수를 계산하도록 구현했습니다.

1. `init(s)`에서 문자열을 배열로 나누고 1의 개수를 구합니다. 문자열의 길이에서 1의 개수를 빼면 처음 제거한 0의 개수가 됩니다.
2. 첫 번째 변환을 반영해 변환 횟수 `n`을 1로 설정합니다. `next`에는 0을 제거한 문자열의 길이를 저장합니다.
3. `convert(next)`에서 `next`의 이진 표현에 포함된 1과 0의 개수를 구합니다. 1의 개수는 다음 변환에 사용할 길이이고, 0의 개수는 추가로 제거할 개수입니다.
4. 변환 횟수와 제거한 0의 개수를 누적합니다. `next`가 1이면 그 이진 표현도 `"1"`이므로 종료합니다.

### 예시
---
입력이 `"110010101001"`일 때의 변환 과정입니다.

| 변환 | 현재 문자열 | 제거한 0 | 남은 길이 | 변환 결과 |
| --- | --- | --- | --- | --- |
| 1 | `110010101001` | 6 | 6 | `110` |
| 2 | `110` | 1 | 2 | `10` |
| 3 | `10` | 1 | 1 | `1` |

총 3번 변환하고 0을 8개 제거하므로 반환값은 `[3, 8]`입니다. 표에는 이해를 돕기 위해 문자열을 표시했지만, 코드에서는 초기 처리 이후 정수 값으로 계산합니다.

## 4. 핵심 개념
---
### Stream으로 1의 개수 세기

`Arrays.stream(list)`와 `filter`를 사용해 `"1"`인 원소만 남기고, `count()`로 개수를 구했습니다. `count()`의 반환 타입은 `long`이므로 반환 배열에 넣을 때 `int`로 변환했습니다.

### 정수의 이진 표현에서 1과 0 세기

정수를 2로 나눈 나머지는 이진 표현의 각 자릿값입니다. 나머지가 1일 때 `remain`을 증가시키고, 나누는 횟수를 `length`에 누적합니다.

- `remain`: 이진 표현에 포함된 1의 개수
- `length - remain`: 이진 표현에 포함된 0의 개수

나머지는 낮은 자리부터 구해지지만, 이 풀이에서는 각 자릿값의 개수만 필요하므로 순서를 뒤집거나 문자열로 조합하지 않아도 됩니다.

## 5. 어려웠던 점과 해결
---
처음에는 `convert`의 반환값을 다음과 같이 사용했습니다.

```java
next = convert(next)[0];
count += convert(next)[1];
```

첫 번째 줄에서 `next`가 갱신되기 때문에 두 번째 호출은 변경된 값을 기준으로 계산합니다. 그 결과, 서로 다른 변환 단계에서 구한 1과 0의 개수를 함께 사용하게 됩니다.

반환값을 임시 배열에 한 번 저장하고, 같은 변환 결과에서 두 값을 꺼내도록 수정했습니다.

```java
int[] tmp = convert(next);
next = tmp[0];
count += tmp[1];
```

하나의 계산에서 나온 여러 결과를 사용할 때는, 입력을 갱신하기 전에 결과를 함께 저장해야 한다는 점을 배웠습니다.

## 6. 새로 배운 점과 개선할 부분
---
다른 사람의 풀이에서 `s.replaceAll("0", "")`로 0을 제거하는 방법을 배웠습니다. 문자열을 직접 변환하면 문제의 흐름을 코드로 간결하게 표현할 수 있습니다.

## 7. 시간·공간 복잡도

`N`은 최초 입력 문자열의 길이입니다. 

- **시간 복잡도: O(N)** — 초기 문자열을 배열로 나누고 1의 개수를 세는 데 O(N)이 걸립니다. 현재는 `init(s)`를 두 번 호출하지만 상수 배이므로 복잡도는 같습니다. 이후 `convert(k)`는 O(log k)이고, 다음 값은 k의 이진 표현에 포함된 1의 개수이므로 최대 ⌊log₂ k⌋ + 1로 줄어듭니다. 후속 처리의 합은 초기 O(N) 처리보다 작아 전체 시간 복잡도는 O(N)입니다.
- **공간 복잡도: O(N)** — `split("")`으로 입력 길이에 비례하는 배열을 만듭니다. 이후 정수 변환 과정에서는 고정된 개수의 변수와 길이 2인 반환 배열을 사용합니다.
