# 문제 이름: 같은 숫자는 싫어

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 리스트  
**소요 시간:** 10분  
**AI 질문:** X

## 1. 문제 요약

주어진 배열에서 연속적으로 나오는 중복 숫자만 하나의 숫자로 바꾸고 다시 반환하도록

- 입력: `[1,1,3,3,0,1,1]`
- 출력: `[1,3,0,1]`

## 2. 나의 문제 접근 법
1. 배열을 값을 하나 씩 보면서 전 단계와 비교해 리스트에 넣을지 말지 결정함.
2. 리스트를 배열로 바꾸어 리턴

## 3. 시간 복잡도
- O(N)

## 4. 시행착오 및 배운 점
- 마지막 리스트를 인트 배열로 반환하는 작업에서 반복문을 쓰고 싶지 않아서 스트림 문법을 찾아봄
