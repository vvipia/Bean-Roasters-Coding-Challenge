# 문제 이름: 올바른 괄호

**출처:** 프로그래머스  
**난이도:** Lv.2  
**유형:** 스택, 문자열  
**소요 시간:** 19분  
**AI 질문:** X

## 1. 문제 요약

주어진 괄호 문자열을 기준에 맞는 괄호 문자열인지 판단하는 값을 리턴
- 입력: `(())()`
- 출력: `true`

## 2. 나의 문제 접근 법
1. 제일 앞이 ')' 일 때 제일 뒤가 '(' 일 떄는 올바르지 않으므로 false 처리를 함
2. 각 문자를 하나씩 읽어오면서 +1 -1을 함
3. 중간에 합이 음수가 되면 false
4. 총합이 0이면 true 나머지 값들은 false 처리

## 3. 시간 복잡도
- O(N)

## 4. 시행착오 및 배운 점
- 스택 문제라 해서 스택으로 풀려고 했으나, 굳이 스택으로 안해도 풀이가 가능해 보여서 중간에 다시 바꿈.
