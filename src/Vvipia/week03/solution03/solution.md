# 문제 이름: 올바른 괄호

**출처:** 프로그래머스  
**난이도:** Lv.2  
**유형:** 문자열, 스택, 구현  
**소요 시간:** 미기록  
**AI 질문:** 

## 1. 문제 요약

여는 괄호 `(`와 닫는 괄호 `)`로 이루어진 문자열 `s`가 주어졌을 때, 모든 괄호가 올바르게 짝지어져 있으면 `true`, 그렇지 않으면 `false`를 반환한다.

- 입력: `s = "()()"`
- 출력: `true`
- 추가 예시: `"(())()"` → `true`
- 추가 예시: `")()("` → `false`
- 추가 예시: `"(()("` → `false`

## 2. 나의 문제 접근 법

1. 여는 괄호와 닫는 괄호의 개수를 관리하기 위해 `count` 변수를 0으로 초기화한다.
2. `for`문을 사용하여 문자열 `s`를 처음부터 끝까지 순회한다.
3. `charAt(i)`를 이용하여 현재 위치의 괄호를 확인한다.
4. 여는 괄호 `(`를 만나면 `count++`, 닫는 괄호 `)`를 만나면 `count--`를 수행한다.
5. 순회 도중 `count < 0`이면 닫는 괄호가 먼저 나온 것이므로 즉시 `false`를 반환한다.
6. 모든 문자를 검사한 후 `count == 0`이면 `true`, 그렇지 않으면 `false`를 반환한다.

## 3. 시간 복잡도

- 문자열 `s`의 길이를 N이라고 가정한다.
- `for`문을 통해 문자열을 최대 N번 순회한다.
- 각 문자에서 괄호 비교와 `count` 증감 연산은 O(1)이 소요된다.
- `count < 0` 조건을 만족하면 즉시 종료하므로 불필요한 연산을 줄일 수 있다.
- 따라서 전체 시간 복잡도는 **O(N)**이다.
- 별도의 배열이나 스택을 사용하지 않고 정수 변수 하나만 사용하므로 공간 복잡도는 **O(1)**이다.

## 4. 시행착오 및 배운 점

- 처음에는 스택을 사용하는 문제라고 생각했지만, 괄호가 한 종류뿐이므로 정수 변수 하나로도 해결할 수 있다는 것을 배웠다.
- 여는 괄호를 만나면 `count`를 증가시키고, 닫는 괄호를 만나면 감소시키는 방식으로 괄호의 짝을 검사할 수 있다는 것을 알게 되었다.
- 단순히 여는 괄호와 닫는 괄호의 개수가 같은지만 확인하면 올바른 괄호를 판별할 수 없다는 점을 이해했다.
- 예를 들어 `")("`는 괄호 개수가 같지만 닫는 괄호가 먼저 등장하므로 올바르지 않다.
- 따라서 문자열을 순회하는 도중 `count`가 음수가 되는 경우도 검사해야 한다는 것을 배웠다.
- `count < 0`이면 이후에 여는 괄호가 등장하더라도 이미 잘못된 괄호 순서를 복구할 수 없으므로 즉시 `false`를 반환할 수 있다는 것을 알게 되었다.
- `String.charAt(i)`를 사용하여 문자열의 특정 위치에 있는 문자를 가져오는 방법을 복습했다.
- `return count == 0;`처럼 비교 연산의 결과를 별도의 `if`문 없이 바로 반환할 수 있다는 것을 배웠다.
- 스택 문제라고 해서 반드시 `Stack` 자료구조를 사용해야 하는 것은 아니며, 문제의 조건에 따라 더 간단한 방법으로 해결할 수 있다는 것을 알게 되었다.
