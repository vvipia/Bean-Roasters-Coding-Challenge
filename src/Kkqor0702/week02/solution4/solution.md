# 문제 이름: 안전지대

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 2차원 배열, 구현  
**소요 시간:** 7분?  
**AI 질문:** X

## 1. 문제 요약

정사각형 배열 board에서 지뢰가 있는 칸과 그 주변 8칸을 위험 지역으로 분류하고, 나머지 안전한 칸의 개수를 반환한다.

- 입력: 지뢰는 1, 빈칸은 0으로 표시된 2차원 배열
- 출력: 안전한 칸의 개수
- 주요 조건: 상하좌우뿐 아니라 대각선으로 인접한 칸도 위험 지역이다.

## 2. 나의 문제 접근법

1. board의 한 변 길이를 len에 저장한다.
2. 가장자리에서도 범위 검사 없이 위험 지역을 표시할 수 있도록
   가로와 세로가 각각 len + 2인 notSafe 배열을 생성한다.
3. 원본의 board[i][j]는 notSafe[i + 1][j + 1]에 대응하도록 한다.
4. board를 순회하면서 지뢰를 발견하면 notSafe의 대응 위치와 주변 8칸을 증가시킨다.
5. 전체 칸 수인 len × len을 safe의 초기값으로 설정한다.
6. notSafe에서 실제 board에 대응하는 행과 열인 1부터 len까지만 순회한다.
7. 값이 0이 아닌 칸마다 safe를 1 감소시킨다.
8. 남은 안전한 칸의 개수를 반환한다.

## 3. 시간 복잡도

- 위험 표시 배열 생성 및 초기화: O (N²)
- board 전체 순회: O (N²)
- 지뢰 하나의 위험 지역 표시: O (1), 총 9칸
- 실제 영역의 위험 칸 집계: O (N²)

**최종 시간 복잡도: O (N²)**  
**공간 복잡도: O (N²)**

※ N = board의 한 변 길이
※ notSafe 배열의 크기는 (N + 2) × (N + 2)이다.

## 4. 시행착오 및 배운 점

- 배열의 가장자리에 한 칸씩 여유 공간을 두어 경계 조건을 처리하였다.
- 원본 배열과 위험 표시 배열의 좌표를 한 칸씩 이동시켜 대응시켰다.
- 여러 지뢰의 위험 지역이 겹쳐도 0이 아닌지만 확인하면 위험 칸을 한 번만 집계할 수 있다.
- 여유 공간은 위험 지역 표시에는 사용하지만, 안전한 칸을 계산할 때는 제외하였다.
- 코드 리뷰에서는 위험 여부만 필요하므로 boolean 배열을 사용할 수 있고,
  반복문으로 3 × 3 영역을 표시하면 나열된 코드를 줄일 수 있음을 확인하였다.
