### 2. 새로 배운 점

- **PriorityQueue와 Comparator**
    - **관련 문제:** Solution 1 — 전국 대회 선발 고사 (`solution1_181851`)
    - 최초 풀이는 참석 가능한 학생의 등수를 배열에 모아 정렬한 뒤, 원래 인덱스를 찾는 방식으로 구현하였다.
    - 풀이 이후 학생의 인덱스를 PriorityQueue에 저장하고, 해당 학생의 등수를 기준으로 우선순위를 정하는 방법을 학습하였다.
    - `(a, b) -> Integer.compare(rank[a], rank[b])`에서 저장하는 값은 인덱스이고, 비교하는 값은 해당 인덱스의 등수라는 점을 이해하였다.
    - Comparator의 반환값이 음수면 a가 먼저, 양수면 b가 먼저 오며, 0이면 비교 기준상 동등하다.
    - 일반적으로 뺄셈으로 비교하면 정수 오버플로가 발생할 수 있어 `Integer.compare()`를 사용할 수 있음을 배웠다.

- **Set의 종류와 자료구조 선택**
    - **관련 문제:** Solution 6 — 폰켓몬 (`solution6`)
    - HashSet으로 중복을 제거하고, 종류 수와 선택 가능한 수 중 작은 값을 반환하였다.
    - HashSet은 원소의 순서를 보장하지 않고, LinkedHashSet은 삽입 순서를 유지하며, TreeSet은 정렬된 순서로 원소를 관리한다는 차이를 학습하였다.
    - 정렬이나 삽입 순서가 필요하지 않은 문제에서는 HashSet으로 중복을 제거할 수 있음을 확인하였다.

- **정렬과 Java Stream**
    - **관련 문제:** Solution 9 — 등수 매기기 (`solution9`)
    - 점수 합계를 내림차순으로 정렬하고, 처음 일치하는 위치를 찾아 동점자의 등수를 처리하였다.
    - `Arrays.stream(average).boxed()`로 int 값을 Integer로 변환하고, `Comparator.reverseOrder()`로 내림차순 정렬하는 방법을 학습하였다.
    - `toArray(Integer[]::new)`로 정렬 결과를 Integer 배열로 만드는 방법을 익혔다.

- **Upper Bound와 Lower Bound**
    - **관련 문제:** Solution 9 — 등수 매기기 (`solution9`)
    - 추가 풀이를 통해 정렬된 배열에서 경계를 찾는 이진 탐색을 학습하였다.
    - Lower Bound는 target 이상인 값이 처음 등장하는 위치이고, Upper Bound는 target보다 큰 값이 처음 등장하는 위치이다.
    - 조건에 맞는 값이 없다면 배열 길이를 반환한다.
    - `[left, right)` 범위와 `left < right` 종료 조건을 정리하였다.
    - Upper Bound를 구하면 `전체 학생 수 - 경계 인덱스`로 현재 점수보다 높은 학생 수를 계산할 수 있음을 배웠다.
    - `left = mid + 1`과 `right = mid`가 각각 어떤 조건에서 사용되는지 중점적으로 공부하였다.
    - `clone()`으로 원본과 같은 값을 가진 별도의 배열을 만드는 방법도 학습하였다.

- **빈도수 배열과 Map 순회**
    - **관련 문제:** Solution 15 — 최빈값 구하기 (`solution15`)
    - 최초 풀이는 크기가 1000인 배열에 숫자별 등장 횟수를 저장하는 방식으로 구현하였다.
    - 입력값의 범위가 작고 정해져 있다면 배열의 인덱스를 숫자 자체로 사용할 수 있음을 확인하였다.
    - `Arrays.stream(arr).max().orElse()`로 최대 빈도수를 구하고, 최대 빈도수를 가진 숫자가 여러 개인지 확인하였다.
    - 추가 학습으로 `Map.Entry`가 Key-Value 한 쌍을 나타내고, `entrySet()`이 모든 쌍을 Set 형태로 반환한다는 점을 정리하였다.
    - `Map.Entry<Integer, Integer>`를 순회하면서 `getKey()`와 `getValue()`로 숫자와 빈도수에 접근하는 방법을 배웠다.

- **문자열 처리**
    - **Solution 2 — 대소문자 바꿔서 출력하기 (`solution2_181949`):** `toCharArray()`로 문자열을 문자 배열로 변환하고, `Character.isLowerCase()`,
      `toUpperCase()`, `toLowerCase()`로 대소문자를 처리하였다.
    - **Solution 3 — 외계어 사전 (`solution3_120869`):** `indexOf()`로 특정 문자의 포함 여부를 확인하였다.
    - **Solution 8 — 저주의 숫자 3 (`solution8`):** 숫자를 문자열로 변환하고, `contains("3")`으로 숫자 3이 포함되어 있는지 검사하였다.
    - **Solution 14 — 다항식 더하기 (`solution14`):** `split()`, `endsWith()`, `substring()`, `Integer.parseInt()`를 사용하여 항을
      분리하고 x항의 계수와 상수를 각각 누적하였다.

- **배열 복사와 범위 처리**
    - **관련 문제:** Solution 13 — 배열 조각하기 (`solution13`)
    - `Arrays.copyOf()`로 배열의 앞부분을 복사하고, `Arrays.copyOfRange()`로 필요한 구간을 복사하였다.
    - `copyOfRange()`의 시작 인덱스는 포함되고, 끝 인덱스는 포함되지 않는다는 점을 학습하였다.
    - 풀이 이후 배열을 반복해서 복사하는 대신 시작과 끝 인덱스를 관리하는 개선 방향을 알아보았다.

- **시간 복잡도 분석**
    - **Solution 9 — 등수 매기기 (`solution9`):** 정렬 비용뿐 아니라 정렬 이후의 탐색 비용도 함께 고려해야 한다는 점을 확인하였다. 최초 풀이는 학생마다 순차 탐색하므로 전체 시간
      복잡도가 O (N²)이 된다.
    - **Solution 13 — 배열 조각하기 (`solution13`):** 반복마다 배열을 복사하므로 최악의 경우 O (Q × N)의 비용이 발생한다. N은 원본 배열 길이, Q는 query 길이이다.
    - **Solution 15 — 최빈값 구하기 (`solution15`):** 시간 복잡도는 O (N + K)이다. N은 입력 배열 길이, K는 빈도수 배열 크기이며, K가 1000으로 고정되어 있다면 N
      기준으로 시간 O (N), 보조 공간 O (1)로 볼 수 있다.
