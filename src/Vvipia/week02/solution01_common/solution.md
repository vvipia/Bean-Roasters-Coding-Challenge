# 문제 이름: K번째수

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 배열, 정렬, Stream  
**소요 시간:** 미기록  
**AI 질문:** O (스트림 문법)

## 1. 문제 요약

정수 배열 `array`와 `[i, j, k]`로 구성된 2차원 배열 `commands`가 주어졌을 때, 각 명령에 따라 배열을 자르고 정렬한 후 k번째 숫자를 반환한다.

- 입력: `array = [1, 5, 2, 6, 3, 7, 4]`
- 명령: `commands = [[2, 5, 3], [4, 4, 1], [1, 7, 3]]`
- 출력: `[5, 6, 3]`

## 2. 나의 문제 접근 법

1. `Arrays.stream(commands)`를 사용하여 각 명령을 순차적으로 처리한다.
2. `command[0]`과 `command[1]`을 이용해 배열의 특정 구간을 추출한다.
3. `sorted()`를 사용하여 추출한 배열을 오름차순으로 정렬한다.
4. 정렬된 배열에서 `command[2] - 1` 인덱스의 값을 가져온다.
5. `mapToInt()`와 `toArray()`를 이용하여 결과를 `int[]` 배열로 반환한다.

## 3. 시간 복잡도

- `commands`의 길이를 M, `array`의 길이를 N이라고 가정한다.
- 각 명령에서 배열 구간을 추출하는 데 최대 O(N)이 소요된다.
- 추출한 배열을 정렬하는 데 최대 O(N log N)이 소요된다.
- 이 과정을 M번 반복하므로 전체 시간 복잡도는 **O(M × N log N)**이다.

## 4. 시행착오 및 배운 점

- 처음에는 `Arrays.stream(array, command[0], command[1])`로 구간을 추출하려 했으나, Java 배열의 인덱스는 0부터 시작하므로 `command[0] - 1`로 보정해야 한다는 점을 배웠다.
- `Arrays.stream()`의 끝 인덱스는 포함되지 않기 때문에 `command[1]`은 그대로 사용하면 된다.
- 배열에는 `stream()` 메서드가 없기 때문에 `Arrays.stream()`을 사용해야 한다는 것을 알게 되었다.
- 처음에는 `map()`으로 결과를 반환한 뒤 `mapToInt()`를 사용하려 했지만, `mapToInt()`에는 변환 함수를 전달해야 한다는 점에서 어려움을 겪었다.
- `map()`은 `Stream<Integer>`를 반환할 수 있지만, `mapToInt()`는 `IntStream`을 반환하므로 최종적으로 `int[]`가 필요한 경우 더 간결하게 처리할 수 있다는 것을 배웠다.
- Stream을 활용하면 반복문 없이 배열 구간 추출, 정렬, 결과 반환을 연결하여 구현할 수 있다는 것을 알게 되었다.
