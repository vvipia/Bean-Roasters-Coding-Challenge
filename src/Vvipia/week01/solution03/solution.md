# 문제 이름: 두 큐 합 같게 만들기

**출처:** 프로그래머스  
**난이도:** Lv.2  
**유형:** 큐
**소요 시간:** 37분  
**AI 질문:** X

## 1. 문제 요약

두 큐가 가지고 있는 정수들의 합이 같게 되도록 각 정수들을 이동시킬때 최소 횟수 구하기.

- 입력: `queue1: [3, 2, 7, 2]   queue2: [4, 6, 5, 1]`
- 출력: `2`

## 2. 나의 문제 접근 법

1. 문제에서는 큐라고 했지만, 실제론 배열로 주어지기 때문에 큐로 변환하는 동시에 각 배열의 합과 총 합을 구한다.
2. 총 합이 2로 나누어 떨어지지 않는 경우 두 큐의 값이 같아질 수 없으므로 예외 처리를 해둔다.
3. 각 큐의 합을 비교해 작은 큐 쪽으로 큰 큐의 제일 앞의 값을 이동 시킨다.
4. 카운트를 증가 시키며 같아질 때의 카운트를 리턴하도록 한다.
5. 무한 루프 방지를 위해 조건을 하나 추가한다.

## 3. 시간 복잡도
- 입력되는 두 큐(배열)의 길이(N)에 따라 반복 횟수가 달라지므로 시간 복잡도는 O(N)

## 4. 시행착오 및 배운 점
- 각 큐의 합이 int 표현 범위보다 커지는 경우가 있어 long으로 바꿔야 했다.
- 무한 루프 방지를 위해 탈출 조건을 정해야 했는데, 각 큐의 길이를 더한 것 보다 카운트가 증가하면 탈출 하도록 하니 테스트 케이스 1개가 실패 했고 각 큐의 길이를 곱한 것을 기준으로 했을 땐 더 많은 테스트 케이스가 실패 했다. 그래서 각 큐 길이의 합에 2를 곱해 처리해 해결 했다.
- 큐에 관한 문법이 기억이 안나 문법만 찾아봤다.
