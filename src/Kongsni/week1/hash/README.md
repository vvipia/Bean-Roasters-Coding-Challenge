# 폰켓몬

## 1. 문제 정보
- 플랫폼: 프로그래머스
- 난이도: Level 1
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/1845
- 사용 언어: Java

## 2. 문제 설명
주어진 폰켓몬 중 전체 마릿수의 절반을 선택할 때, 서로 다른 종류를 최대 몇 개까지 선택할 수 있는지 구하는 문제입니다.

## 3. 접근 방법
처음에는 중복된 숫자를 어떻게 처리해야 할지 고민했습니다.

같은 번호는 같은 종류의 폰켓몬이기 때문에 중복을 제거할 수 있는 `HashSet`을 사용했습니다.

1. `HashSet`을 생성합니다.
2. 반복문을 사용해 배열의 모든 숫자를 `HashSet`에 추가합니다.
3. `size()`를 이용해 서로 다른 종류의 개수를 구합니다.
4. 전체 폰켓몬 수의 절반과 서로 다른 종류의 개수 중 작은 값을 반환합니다.

## 4. 핵심 개념
- `HashSet`: 중복된 값을 저장하지 않는 자료구조
- `add()`: 데이터를 추가하는 메서드
- `size()`: 저장된 원소의 개수를 반환하는 메서드
- `Math.min()`: 두 값 중 작은 값을 반환하는 메서드

## 5. 어려웠던 점
중복된 숫자를 제거하는 방법과 서로 다른 종류의 개수를 구한 뒤 어떤 값을 반환해야 하는지 이해하는 것이 어려웠습니다.

특히 서로 다른 종류가 많더라도 선택할 수 있는 마릿수를 초과할 수 없다는 점을 이해하게 되었습니다.

## 6. 새로 배운 점
- `HashSet`을 사용하면 중복된 데이터를 쉽게 제거할 수 있다는 것을 배웠습니다.
- `Math.min()`을 이용해 두 숫자 중 작은 값을 구할 수 있다는 것을 알게 되었습니다.
- 문제의 조건을 먼저 파악한 뒤 적절한 자료구조를 선택하는 것이 중요하다고 느꼈습니다.

## 7. 시간 복잡도
- 시간 복잡도: 평균 O(N)
- 공간 복잡도: O(N)
