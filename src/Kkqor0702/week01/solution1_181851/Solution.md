# 문제 이름: 전국 대회 선발 고사

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 정렬, 구현, 배열  
**소요 시간:** ?  
**AI 질문:** X

## 1. 문제 요약

int 배열 하나, boolean 배열 하나가 주어지는데,
여기서 true인 boolean 배열이 true인 인덱스 중 숫자가 낮은 순서대로 각각 a, b, c 번 인덱스라고 할 때,
10000 *a + 100*b + c 값을 return

- 입력: `[3, 7, 2, 5, 4, 6, 1], [false, true, true, true, true, false, false]`
- 출력: `20403`

## 2. 나의 문제 접근 법

1. 우선 true 인 배열에서만 후보가 정해지니까 boolean 배열을 돌아 true의 개수를 세어 해당 수만큼의 int형 배열을 만든다.
2. true인 인덱스들의 숫자만 모아 새로운 배열을 만든다.
3. 오름차순으로 정렬하여 0, 1, 2 인덱스로 낮은 숫자에 접근할 수 있게 한다.
4. 원래 int형 배열에서 해당 수가 몇번째 인덱스에 있는지 반환하여 answer에 요구대로 더한다.

## 3. 시간 복잡도

- int형 배열을 정렬했으므로 nlogn으로 추측

## 4. 시행착오 및 배운 점

- 우선순위 큐나, 맵으로 푸는 방식을 생각했다가 어떻게 구현할지 몰라 무식한 방식으로 구현하여 더 좋은 방법이 있는지 알아보아야겠다.

### 1. 기본 PriorityQueue

Java의 `PriorityQueue` 는 기본적으로 최소 힙

별도의 조건이 없으면 숫자가 작은 값부터 꺼내짐

숫자 자체가 아닌 다른 기준으로 우선순위를 정하고 싶다면?
→ `Comparator` 사용

### 2. Comparator란?

두 값을 비교해서 우선순위를 결정하는 인터페이스

`(a, b) → Integer.compare(a,b)`

| 비교 결과 | 의미                    |
|-----------|-------------------------|
| 음수      | a가 b보다 앞에 온다     |
| 0         | a와 b의 우선순위가 같다 |
| 양수      | b가 a보다 앞에 온다     |

개념적으로 `a - b` 의 부호를 판단한다고

음수 → a가 먼저
양수 → b가 먼저
0: 동등한 우선순위

### 3. 이 문제에서

`(a, b) -> Integer.compare(rank[a], rank[b])`

`(a, b) -> rank[a] - rank[b]`
→ 정수 오버플로가 발생할 수 있음

a와 b의 값이 아닌,
a와 b를 인덱스로 사용해서 `rank` 배열의 값을 비교

`int[] rank = {3, 7, 2, 5, 4, 6, 1}` 이 있을 때,

저장된 값은 인덱스지만, 우선순위는 해당 인덱스가 가리키는 배열의 값으로 결정 !
