# 문제 이름: 위장

**출처:** 프로그래머스  
**난이도:** Lv.2  
**유형:** 해시
**소요 시간:** 37분  
**AI 질문:** O

## 1. 문제 요약

옷의 종류와 이름이 주어진다. 같은 종류가 중복되지 않게 옷을 착용할 수 있는 경우의 수를 구하기

- 입력: `[["yellow_hat", "headgear"], ["blue_sunglasses", "eyewear"], ["green_turban", "headgear"]]`
- 출력: `5`

## 2. 나의 문제 접근 법
### 첫 번째 풀이 (오답)
1. 해시 맵을 이용해 각 옷들이 소속된 종류가 몇 개 중복되는 지를 저장
2. 해시 셋을 이용해 종류만 저장
3. 총 옷들의 갯수 + 각 종류들의 곱 을 리턴

### 두 번째 풀이
1. 첫 번째 문제를 풀면서 누락된 경우의 수가 있다는 것을 파악
2. 모든 경우의 수를 구하는 법을 떠올리긴 했지만 구현을 어떻게 해야 할지 생각이 나지 않음
3. ai를 통해 해당 부분 대해 힌트를 얻음

## 3. 시간 복잡도
- O(N)

## 4. 시행착오 및 배운 점
- 경우의 수 각각 나누어서 덧셈으로 계산하려는 접근을 하다 보니 중간에 풀이가 막힘
- 이번 문제의 경우 선택지를 확장해서 곱셈으로 한 번으로 모든 경우를 계산한 후 예외 경우만 뺌
- ai 피셜: 이런 사고방식을 곱의 법칙이라고 하며, 코딩 테스트에서 자주 등장하니까 기억하라 함
- 추가적으로 HashMap의 values() 이용하면 HashSet 각 키의 값을 가져올 수 있음을 알게 됨
