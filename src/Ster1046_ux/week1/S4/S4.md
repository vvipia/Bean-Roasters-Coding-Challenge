# 문제 이름: 대문자와 소문자

- **출처:** 프로그래머스
- **난이도:** Lv.0
- **유형:** 문자열, 구현
- **소요 시간:** 미기록
- **AI 질문:** O

## 1. 문제 요약

문자열 `my_string`의 대문자는 소문자로,
소문자는 대문자로 변환하여 반환한다.

- 입력: `"cccCCC"`
- 출력: `"CCCccc"`

## 2. 나의 문제 접근 법

1. 변환한 결과를 담을 문자열 `answer`를 빈 문자열로 초기화한다.
2. 반복문과 `charAt(i)`로 문자열에서 한 글자씩 꺼낸다.
3. `Character.isUpperCase(ch)`로 대문자인지 확인한다.
4. 대문자는 `Character.toLowerCase(ch)`로 소문자로 변환한다.
5. 소문자는 `Character.toUpperCase(ch)`로 대문자로 변환한다.
6. 변환한 글자를 `answer`에 `+=`로 이어 붙인다.
7. 반복문이 끝나면 완성된 문자열을 반환한다.

## 3. 시간 복잡도

- **O(N²)** — N은 문자열 길이이다. 반복문에서 문자열을 이어 붙일 때 기존 내용도 복사하므로, 누적되는 복사량을 고려하면 O(N²)이다.
- **공간 복잡도: O(N)** — 길이 N의 결과 문자열을 저장한다.

## 4. 시행착오 및 배운 점

- `String` 변수에 `char` 값을 `+=`로 이어 붙여, 변환한 글자를 순서대로 누적할 수 있다는 점을 배웠다.
