# 문제 이름: 등수 매기기

**출처:** 프로그래머스  
**난이도:** Lv.0  
**유형:** 구현, 정렬, 배열  
**소요 시간:** 15분  
**AI 질문:** O

- (`int[]` → `Integer[]` 변환 및 정렬)

## 1. 문제 요약

영어 점수와 수학 점수의 평균을 기준으로 학생들의 등수를 매기는 문제.
평균이 같은 학생은 동일한 등수를 부여한다.

- 입력: `[[80, 70], [90, 50], [40, 70], [50, 80]]`
- 출력: `[1, 2, 4, 3]`

## 2. 나의 문제 접근 법

1. 모든 학생의 과목 수가 동일하므로 평균 대신 두 점수의 합계를 계산한다.
2. 합계를 `average` 배열에 저장한다.
3. 원본 배열을 유지하면서 내림차순 정렬하기 위해 별도의 `sortAverage` 배열을 생성한다.
4. `Arrays.stream().boxed().sorted()`를 활용하여 내림차순으로 정렬한다.
5. 원본 배열의 각 점수를 정렬된 배열에서 순차적으로 탐색한다.
6. 처음 일치하는 위치를 등수로 사용하여 동점자에게 동일한 등수를 부여한다.

## 3. 시간 복잡도

- 등수 탐색에서 2중 반복문 -> O (n^2)
- -> O (nlogn)으로 개선 가능

## 4. 시행착오 및 배운 점

- 오름차순 정렬을 어떻게 하는지 찾아보았다.
    - Integer 형으로 바꾸어야 해서
  ```Java
  Integer[] sortAverage = Arrays.stream(average)
                .boxed()
                .sorted(Comparator.reverseOrder())
                .toArray(Integer[]::new);
  ```
- 추가적으로 알아본 풀이
    - `Upper Bound` 를 이용해 현재 점수보다 큰 학생 수 계산
        - `.clone` 으로 원본 배열과 동일한 값을 가진 새로운 배열을 생성할 수 있음
    - `indexOf` 함수를 이용하여 어느 index 위치에 있는지 `List` 를 활용해서
