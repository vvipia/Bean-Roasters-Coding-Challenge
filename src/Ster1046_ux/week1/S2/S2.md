# 문제 이름: 배열 원소의 길이

- **출처:** 프로그래머스
- **난이도:** Lv.0
- **유형:** 배열, 문자열, 구현
- **소요 시간:** 미기록


## 1. 문제 요약

문자열 배열 `strlist`의 각 원소에 대해 글자 수를 구하고,
입력 순서대로 정수 배열에 담아 반환한다.

- 입력: `["We", "are", "the", "world!"]`
- 출력: `[2, 3, 3, 6]`

## 2. 나의 문제 접근 법

1. 입력 배열의 원소 개수만큼 정수 배열 `answer`를 생성한다.
2. 반복문으로 `strlist`의 각 문자열을 순서대로 확인한다.
3. `strlist[i].length()`로 해당 문자열의 글자 수를 구한다.
4. 구한 글자 수를 `answer[i]`에 저장한다.
5. 완성된 배열을 반환한다.

## 3. 시간 복잡도

- **O(N)** — N은 입력 배열의 원소 개수이다. 각 원소를 한 번씩 확인한다.
- **공간 복잡도: O(N)** — 각 문자열의 길이를 저장할 결과 배열을 생성한다.

## 4. 시행착오 및 배운 점

- 배열의 `length`는 원소 개수, 문자열의 `length()`는 글자 수.
