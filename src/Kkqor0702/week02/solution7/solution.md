# 문제 이름: K번째수

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 배열, 정렬  
**소요 시간:** ?  
**AI 질문:** X

## 1. 문제 요약

각 명령 [i, j, k]에 대해 배열의 i번째부터 j번째까지 정렬했을 때, 해당 구간의 k번째 숫자를 반환한다.

- 입력:
    - array = [1, 5, 2, 6, 3, 7, 4]
    - commands = [[2, 5, 3], [4, 4, 1], [1, 7, 3]]
- 출력: [5, 6, 3]
- 주요 조건: 명령의 위치는 1부터 시작한다.

## 2. 나의 문제 접근법

1. 명령 개수만큼 결과 배열을 생성한다.
2. 각 명령마다 array.clone ()으로 원본 배열 전체를 복사한다.
3. Arrays.sort (clone, command[0] - 1, command[1])로 지정된 구간만 정렬한다.
4. 구간의 시작 인덱스에 k - 1을 더하여 k번째 원소의 위치를 계산한다.
    - (i - 1) + (k - 1) = i + k - 2
5. 해당 위치의 값을 결과 배열에 순서대로 저장한다.
6. 모든 명령의 처리 결과를 반환한다.

## 3. 시간 복잡도

- 명령 하나당 전체 배열 복사: O (N)
- 명령 하나당 구간 정렬: O (L log L)
- 정답 원소 접근 및 저장: O (1)

**최종 시간 복잡도: 최악 O (M × N log N)**  
**공간 복잡도: O (N + M)**

※ N = 원본 배열 길이
※ M = 명령 개수
※ L = 각 명령에서 정렬하는 구간의 길이
※ 명령 하나의 처리 비용은 O (N + L log L)이다.
※ 공간 복잡도는 복사 배열과 결과 배열을 포함하며,
결과 배열을 제외한 보조 공간은 O (N)이다.

## 4. 시행착오 및 배운 점

- clone ()으로 원본 배열을 보존하면서 각 명령을 독립적으로 처리하였다.
- Arrays.sort ()에 범위를 지정하면 배열의 일부 구간만 정렬할 수 있다.
- 풀이 이후 Arrays.sort ()와 Arrays.copyOfRange ()의 범위가
  시작 포함·끝 제외인 [fromIndex, toIndex)라는 점을 질문하고 정리하였다.
- 끝 인덱스를 제외하면 구간 길이를 toIndex - fromIndex로 계산할 수 있다.
- 전체 배열을 복사한 풀이에서는 구간의 시작 위치가 유지되므로,
  k번째 값에 접근할 때 시작 인덱스를 더해야 한다.
- 필요한 구간만 복사하면 복사량과 정답 인덱스 계산을 줄일 수 있다.
