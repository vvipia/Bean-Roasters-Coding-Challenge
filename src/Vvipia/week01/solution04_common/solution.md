# 문제 이름: 폰켓몬

**출처:** 프로그래머스  
**난이도:** Lv.1  
**유형:** 해시
**소요 시간:** 11분  
**AI 질문:** X

## 1. 문제 요약

연구실 폰켓몬 최대 수의 N/2 폰켓몬을 가져가는 경우, 가져가는 폰켓몬의 최대 종류 수

- 입력: `[3,1,2,3]`
- 출력: `2`

## 2. 나의 문제 접근 법

1. 중복 수 제거를 위해 해시 셋에 배열의 값들을 넣는다.
2. 중복이 제거된 셋의 길이를 구한다.
3. 셋의 길이와 기존 배열 / 2 값중 작은 값을 리턴한다.

## 3. 시간 복잡도
- 배열 길이 만큼 반복문이 반복 되므로 시간 복잡도는 O(N)

## 4. 시행착오 및 배운 점
- 해시 셋 문법만 살짝 찾아봤다.
